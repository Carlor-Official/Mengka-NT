# 萌卡 NT v1.4.1

## 更新

本版本重点改善容器安装体验，让国内与海外环境都能更稳定地完成初始化。

- 容器镜像会先检测可用线路，并优先选择当前响应更快的线路。
- 当前线路失败时会自动切换下一条线路，避免因单一镜像站异常而一直卡住。
- 除 Docker Hub 外，其他公开镜像仓库也可使用通用备用线路，后续安装更多 Docker 内容同样生效。
- 容器设置中预置国内与海外常用线路，仍可按需增删或留空使用 Docker 默认源。
- 修复服务器已有 PostgreSQL 或 Redis 占用默认端口时安装失败的问题，框架会自动选择空闲的本地端口并继续连接。
- 容器拉取过程增加明确的线路检测、切换与结果日志，便于查看当前进度和定位失败原因。

### 外发平台

- Windows AMD64
- Linux AMD64
- Linux ARM64

## 升级说明

- 直接使用对应平台的 v1.4.1 外发包覆盖程序文件，保留原有 `data` 目录。
- 如果旧配置中尚未设置镜像加速，首次安装容器时会写入默认线路并短暂重启一次 Docker 服务；已有自定义配置不会被覆盖。
