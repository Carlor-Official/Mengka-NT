# 萌卡NT v3.0.3

## 新增

- 新增免费小说等级任务，支持手动执行和定时计划。
- 新增等级任务全局配置，可统一保存任务开关与每日执行时间。
- 新增等级任务批量应用，支持搜索、多选账号，并查看各账号的应用结果。
- 群历史消息接口补充 all_msg_filtered、share_history_msg_flag 返回字段；仅在 QQ 实际返回时提供。
- 新增电脑在线任务自动添加账号：没有对应 Linux 账号时，沿用安卓账号的信息、设备指纹和节点，自动添加并尝试免扫登录。
- 新增 Windows 首次交互启动端口选择；Linux 安装包提供可直接编辑的端口配置文件。

## 优化

- 优化全局配置与单账号等级任务页面，统一按钮尺寸、间距和排列。
- 优化自动执行开关；将批量开启、关闭操作合并为一个按钮，根据当前状态切换“开启全部”和“关闭全部”。
- 优化等级任务的手机端布局与批量应用弹窗，改善小屏幕下的操作体验。
- 优化免费小说任务的取消、超时和结果待确认提示。
- 优化音乐、福利券和 QQ 宠物任务的异常提示，减少难以理解的报错。
- 优化小游戏登录与元宝注册提示，提供对应的登录、授权或注册操作指引。
- 优化元宝任务异常提示，区分材料过期、账号不匹配和任务中断。
- 优化等级任务错误信息处理，避免在页面和日志中暴露敏感内容。

## 修复

- 修复累计签名上下文被误当作账号容量，导致尚有离线账号时提示签名实例达到上限的问题；取消框架及验证端的账号、签名上下文数量限制。
- 修复部分主题色切换不完整，以及石墨主题按钮文字对比度不足的问题。
- 修复账号列表在较窄窗口中活跃时长逐字换行、导致行高异常的问题。
- 修复单框架在线账号数量较多时停止上报、导致仪表盘统计缺失的问题。
- 修复客户端与验证端存在时钟偏差时，部分有效元宝材料被误判为账号不匹配的问题。
- 修复 Linux ARM64 安装包缺失的问题，恢复提供完整安装包。
- 修复免费小说任务奖励标签未显示的问题。
- 修复首次登录信息获取失败后，QQ 等级和会员信息长时间无法自动更新的问题。
- 修复部分任务在账号退出或重新登录后的状态检查问题。
- 修复福利券领取过程中可能重复提交请求的问题。
- 修复 Linux 免扫登录需要安全确认时提前关闭二维码的问题。
- 修复 Linux 免扫登录可能选用其他节点安卓账号的问题。
- 修复私有测试版本在线更新时，下载较慢可能中断、导致更新无法完成的问题。

## 升级说明

升级前请备份完整 data 目录与插件数据。手动升级时，请先停止框架，再替换程序和配套 public 静态资源。保留原 data 目录，无需重新使用注册卡。

首次部署请下载对应系统和处理器架构的完整安装包，使用注册卡完成初始化。Windows 提供 AMD64 / x86_64 安装包；Linux 提供 AMD64 / x86_64 和 ARM64 / AArch64 安装包。
