# 萌卡 NT v1.3.11

## 更新

- 插件市场打开和切换页面更快：云端列表会短时缓存，已经上架的插件不再逐篇读取文章正文。
- 手动点击“刷新”仍会立即获取云端最新插件，不受缓存影响。
- 插件详情改为展示当前版本更新日志，支持 Markdown 排版。
- 开发者发布更新时可从 GitHub 或 Gitee Release 自动读取最新版本、附件和更新说明；Windows 与 Linux 共用统一的“更新日志地址”。
- 官网会每 24 小时检查一次已上架插件的发行页，自动同步新版本信息。

## 升级说明

- Windows、Linux AMD64 和 Linux ARM64 用户均可直接升级。
- 本次升级不会删除账号、配置、已安装插件或运行数据。
- 外发包只包含可执行程序、运行数据和前端静态资源，不包含源码。
