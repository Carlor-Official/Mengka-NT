# 萌卡 NT v1.5.5

## 更新

本次版本重点修复部分部署中好友私聊调用超时的问题，并重新梳理用户端账号、商品和移动端操作流程。

## 修复

### 好友私聊稳定性

- 修复部分环境调用 `send_friend_msg` 时长时间等待并返回 `wait serverResp timeout` 的问题。
- 账号登录后会主动同步好友身份信息；缓存缺失时会按需刷新，再执行私聊发送。
- 好友图片上传与好友消息发送使用同一套身份解析流程，避免同类接口出现不一致。
- 无法确认目标好友时返回明确错误，不再使用可能导致请求无响应的错误回退值。
- 插件 API 参数保持兼容，现有插件无需修改调用方式。

### 用户端业务流程

- 修复管理员删除 QQ 账号时误删 user 端用户的严重问题；用户身份、余额、订单和交易记录会继续保留。
- 重新整理添加账号流程：已有框架账号会引导用户先找回同步，未激活账号可先添加后再选择激活方式。
- 账号激活与续费支持卡密、余额商品和在线支付，商品购买可直接完成目标 QQ 的激活或续费。
- 账号列表与框架管理端保持一致，并将找回、登录、续费、邮件通知等操作集中到账号操作菜单。

## 优化

### 手机端体验

- 管理端和 user 端改为更接近原生 App 的移动布局与底部导航。
- 表格型页面在手机端使用信息卡片展示，优化账号、用户、商品、卡密、支付和设置等页面。
- 清理重复容器与“框套框”布局，修复内容被裁切、横向溢出和操作按钮难以触达的问题。

## 调整

### 消息兼容

- 增加 QQ 自带表情代码兼容，支持 `[bq<表情ID>]` 格式。
- 保留 Unicode Emoji 直接发送能力，并完善群聊、私聊及组合消息中的表情处理。

## 升级说明

- Windows 10/11 64 位：下载 `mengka-nt-v1.5.5-windows-amd64.zip`。
- Linux x86_64：下载 `mengka-nt-v1.5.5-linux-amd64.tar.gz`。
- Linux ARM64：下载 `mengka-nt-v1.5.5-linux-arm64.tar.gz`。
- 升级前请停止框架并备份原有 `data` 目录。完整解压新包后替换程序与前端资源，不要用空数据目录覆盖现有运行数据。
- 本次未改变插件 WebSocket API；现有 Manifest v2 插件无需重新适配。
