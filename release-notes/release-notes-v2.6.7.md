# 萌卡 NT v2.6.7

## 调整

- 下线安卓 9.1.70 协议，保留安卓 9.2.70 和 Linux。
- 调整部分 API 的 QQ 等级要求：Free 为 48 级，Plus 保留 16 级。

## 新增

- 管理员菜单新增 Free／Plus 账号类型显示。

## 优化

- 完善多账号签名与设备缓存隔离，减少账号之间相互影响。
- 修正小程序卡片、群合并转发等接口文档及调试参数说明。

## 修复

- 修复云签名核心异常后，残留会话阻止重新加载的问题。
- 修复部分群信息、群消息历史及修改群名后的校验异常。
- 修复群文件重命名、移动、删除时误报文件路径无权限的问题。
- 修复群签到结果识别及部分插件调用农场接口失败的问题。

## 升级说明

保留原有数据目录进行更新。仍使用 9.1.70 的账号，需要编辑为 9.2.70 后重新登录。
