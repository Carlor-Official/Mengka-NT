# 萌卡 NT v1.9.6

本版本完成框架与萌卡用户系统插件的管理能力衔接，并统一两端的界面体验。

## 核心更新

- 新增受控的系统管理插件权限，可通过官方 SDK 管理多节点账号、指纹、节点、账号设置、登录验证与授权状态。
- 正向 SDK、反向 SDK及插件示例统一为 218 个 action；新增 22 个管理 action 仅对管理员明确授权的服务开放。
- 插件服务页新增用户系统管理入口，支持一次性 SSO 登录；授权码短时有效且只能使用一次。
- 框架 WebUI 同步用户系统插件的字体、玻璃材质、卡片和控件交互，桌面端与手机端保持一致。
- 手机端保留在线更新入口，账号、指纹、节点与等级加速继续使用框架原生逻辑。
- Android 与 Linux QQ 继续按协议独立分流，Linux 扫码、缓存登录和重连链路保持不变。

## 升级说明

升级前请完整备份原目录中的 `data`。停止旧版本后替换程序文件和 `public` 前端资源，并保留原有数据库与管理员配置。

系统管理权限默认关闭；只有确认可信的插件服务才应启用，并填写对应的插件管理端基础地址。

外发包不包含数据库、管理员配置、日志、源码、密钥或 Git 元数据。
