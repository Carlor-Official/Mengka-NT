# 萌卡NT v3.0.7

## 新增

- 新增登录安全验证续接功能，支持继续当前账号的安全验证流程。
- 新增群消息表情回应功能，支持添加或取消表情回应。

## 优化

- 调整接口权益判断范围：普通 API 取消额外 QQ 等级门槛；Free 禁用的指定功能，Plus 在 QQ 达到 32 级并核验通过后开放，Pro 不设这些附加限制。账号页正常扫码和免扫登录保持可用。
- Windows IPC 插件恢复直接导入和运行，无需 Docker；Linux IPC 插件继续使用 Docker 隔离运行，优化环境检测、准备及升级后的环境恢复。
- 更新 Android 与 Linux 协议兼容处理，改善登录认证与状态恢复。
- 优化账号、概览、设备指纹与插件状态同步，减少重复采集，改善断线后的状态刷新。
- 账号最近日志聚焦登录、初始化、连接、心跳及异常信息，不再显示普通消息收发摘要。
- 改进群历史消息接口兼容性，支持获取服务端最新一页消息，并保留原有返回格式。
- 同步框架内 API 调试、SDK 和官网 API 文档，补齐新增接口、参数要求、协议差异与停用标记。

## 修复

- 修复部分网络中断或响应读取超时后，验证连接恢复失败的问题。
- 修复部分红包详情数字字段格式变化导致解析异常的问题。
- 修复账号状态和日志的旧请求结果覆盖最新状态，以及不完整响应覆盖现有数据的问题。
- 修复消息统计、每日峰值及部分任务日期处理中的时区遗漏，统一按上海时区计算自然日。
- 修正 `set_msg_emoji_like` 在 API 调试、SDK 和文档中将 `emoji_id` 标为可选参数的问题。
