# 萌卡 NT v1.4.7 公测版

## 修复

- 修复账号连续在线数小时后，因网页票据刷新流程异常出现“身份验证失败，请重新登录（S26 / W21）”并掉线的问题。
- 区分常规登录票据刷新与网页票据刷新，避免不同刷新流程互相覆盖登录状态。
- 网页票据刷新成功后立即保存最新缓存，降低服务重启后重复登录或缓存失效的概率。
- 修复服务重启后，普通请求错误被误判为会话失效并清空登录缓存，导致账号转入密码登录和安全验证的问题。
- 收紧缓存失效判断：仅在明确出现 W21、S26 或登录凭证失效时清除缓存；临时服务错误与未知错误会保留缓存以便重试。

## 优化

- 增强票据过期、刷新结果和会话失效的运行日志，便于继续观察长时间在线稳定性。
- 诊断日志仅记录流程、返回码和票据类型，不记录账号密码或票据内容。
- 卡密列表将“使用用户”和“使用账号”拆分为独立列，并支持按卡密、用户或 QQ 账号搜索。

## 更新

### 公测说明

- 本版本重点验证 QQ 长时间在线、SID 票据过期自动刷新以及框架重启后的缓存登录稳定性。
- 若账号已经显示 S26 或 W21，升级后需要手动完成一次账号登录；已有失效缓存无法自动恢复。
- 请直接替换程序文件，并保留原有 `data` 目录和数据库配置。
- 如再次出现掉线，请反馈出现时间、提示代码和对应账号日志，请勿提供账号密码或登录票据。
