# 萌卡 NT v1.4.4

## 新增

- 新增无容器兼容模式。Windows 10 及以上系统如果缺少 WSL2、未开启虚拟化或不具备 Docker 运行条件，框架会自动使用本地数据模式继续运行，不再卡在 Docker 安装或反复提示重启。
- 容器页面会明确显示当前兼容状态，避免用户误以为 Docker 启动失败。

## 修复

- 修复宝塔本身运行在 Docker 中时，框架错误调用 `systemctl` 导致 Docker Engine 无法启动的问题。
- 修复宝塔 Docker 部署下 PostgreSQL、Redis 地址识别错误，造成服务显示已启动但框架无法连接的问题。
- 修复升级时保留旧 PostgreSQL、Redis 容器后，本地端口或凭据不一致导致 `connection refused`、`WRONGPASS` 的问题；框架现在会自动识别并同步现有容器配置。
- 修复本地数据模式在高并发下可能出现写入等待、更新失败或 `database is locked` 的问题。

## 优化

- 本地数据启用 WAL、延长写锁等待并使用原子更新，减少并发写入冲突。
- 高频消息统计改为进程内聚合并定时批量保存，查询时会与已有历史数据合并，避免每条消息直接争抢数据库写锁，同时确保重启后数据仍然保留。
- PostgreSQL、Redis 容器重启或框架升级后会自动重新检查连接并恢复服务。

## 升级说明

- 直接替换程序文件即可，原有 `data` 目录请继续保留。
- 宝塔以 Docker 方式部署时，需要将宿主机 `/var/run/docker.sock` 映射到框架所在容器的同一路径。
- Windows 7/8 不在当前程序运行环境支持范围；建议升级系统，或将框架部署在 Linux 服务器后通过浏览器使用。
