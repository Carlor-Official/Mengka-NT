# 萌卡 NT v2.2.1

- 新增 `get_flash_image`：插件可按接收账号、登录协议和消息 ID 获取闪照原图地址、尺寸、文件大小及 MD5。
- 新增独立的 `flash_image` 消息段，便于插件识别闪照；支持解析 QQ 提供的私聊下载路径，解决消息没有直接附带原图 URL 时无法获取的问题。
- 同步在线 API 调试目录、官网 API 文档和正反向 Node.js SDK，公开 API 增至 234 个。

## 使用与升级说明

- 请同步升级框架、前端和 SDK 至 2.2.1。手动升级替换主程序与 `public`，保留 `data` 中的配置和业务数据。
- 在实时收到闪照后，使用外层事件的 `message_id` 调用接口。元数据仅保存在当前账号协议的登录会话内，最多保留 2 分钟；重登或重启后失效。
- 调试预览和消息接收不会自动下载图片。接口返回原图地址，实际有效性由 QQ 服务端决定，无法恢复已失效的内容。
- Android、Linux QQ 接收私聊闪照已通过原图下载、大小和 MD5 校验；群聊闪照尚未实测。
