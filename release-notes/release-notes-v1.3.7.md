# 萌卡 NT v1.3.7

## 更新

### 好友宠物互动

- 新增好友宠物资料查询，可直接查看好友宠物名称、当前心情、饱腹度和清洁度。
- 支持使用食物给好友宠物喂食，也可以使用洗护用品帮助好友宠物清洁。
- 新增访问好友宠物功能，框架会自动识别好友当前的宠物和可用访问方式。

### 宠物 PK

- 补齐宠物 PK 的开始、状态查询和结算流程。
- 发起 PK 时只需选择好友 QQ，框架会自动查找对方的宠物，无需手动填写宠物 ID。
- 保留好友列表和战力查询，方便插件完整展示可挑战对象。

### 学习、打工与冒险

- 打工和冒险现在可以选择雇佣好友宠物参与。
- 获取活动选项时会根据所选好友自动返回当前可执行内容。
- 学习、打工、冒险仍沿用原有调用方式，不使用好友功能的插件无需修改。

### 插件开发支持

- 正向和反向 WebSocket SDK 已同步全部新增宠物接口。
- 新接口只需要 QQ 号、食物名称、用品名称或任务 ID，宠物 ID 和活动参数由框架自动处理。
- API 文档补充了调用参数、返回内容和示例。

## 升级说明

1. 停止正在运行的萌卡 NT，并完整备份原安装目录中的 `data` 目录。
2. 根据系统和 CPU 架构下载对应外发包并解压。
3. 替换程序文件和 `public` 静态资源，同时更新包内的 `data/protocol.json`、`init.sql`、`migrations.sql`、`policy.bin`。
4. 保留原有数据库、账号配置、登录缓存和插件数据，再启动新版本。
5. 使用宠物功能前，请确认对应 QQ 已在手机 QQ 中开通宠物。

Windows 用户请选择 `windows-amd64.zip`；常见 Linux 服务器请选择 `linux-amd64.tar.gz`；ARM 服务器请选择 `linux-arm64.tar.gz`。
