# 萌卡 NT v1.9.0

本版本正式上线 Linux QQ 原生协议，并对账号管理、API 使用体验和前后端稳定性进行集中优化。

## 核心更新

- Linux QQ 原生协议正式上线，提供独立于 Android 协议的账号登录与运行流程。
- 支持通过 Linux QQ 二维码完成登录，并在管理后台统一管理不同协议的账号。
- Android 与 Linux QQ 的协议边界更加清晰，插件可按账号协议选择对应能力。

## 主要优化

- 优化账号添加、扫码登录、状态恢复和异常提示。
- 优化 Web 与手机端管理界面的操作体验和响应式布局。
- 完善 API 与 Node.js SDK 的协议选择、参数一致性和使用说明。
- 提升登录轮询、连接管理及常见异常场景下的稳定性。

## 升级说明

升级前请完整备份原目录中的 `data`。停止旧版本后，替换程序文件和 `public` 前端资源，并保留原有数据与管理员配置。Linux QQ 首次登录请在账号管理中选择 Linux 协议并重新生成二维码。

外发包不包含数据库、管理员配置、日志、源码、密钥或 Git 元数据。实际 QQ 功能仍受账号状态和 QQ 服务端状态影响。
