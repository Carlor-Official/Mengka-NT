# 萌卡 NT v2.1.9

- 改善托管插件的升级兼容性：框架升级正常完成，插件隔离环境在新版本启动后后台准备，避免依赖缺失影响框架更新。
- Linux 支持通过系统软件源自动安装或更新所需隔离依赖；准备失败会保留插件数据和启动状态，后台自动重试，环境恢复后继续启动。插件卡片显示准备进度，并提供“停止自动恢复”。
- 修复旧版本因缺少隔离依赖或运行权限导致的插件启动失败无法自动恢复的问题，继续保留插件隔离与授权校验。
- 插件市场下载新增动态进度条，按实际下载量平滑推进并显示百分比；文件总大小未知时显示循环动画，适配深色主题、手机布局和减少动态效果设置。
- 修复 `buy_pet_bath_item` 向上游发送商品编号的编码错误，避免数字字符串商品编号被错误识别。接口继续接受目录返回的 `item_id` 字符串，数量业务校验仍仅要求 `count > 0`；同步调试说明、SDK 和 API 文档。感谢协议资料贡献者 **星空花海**。

## 升级说明

1. 升级前备份 `data`。手动升级时停止框架与托管插件，替换主程序和 `public`，保留原有配置及业务数据。
2. Linux 托管插件仍需框架以 root 系统服务运行，并且宿主机或容器支持所需内核隔离能力。首次补全依赖可能需要数分钟，请保持软件源与网络可用；没有相应权限或系统不支持时，框架升级仍会完成，插件会提示原因并等待环境恢复，无需卸载重装。
3. 已手动停止、已卸载或授权失效的插件不会因环境恢复而自动启动。可在插件卡片的“更多操作”中停止自动恢复。
4. QQ 宠物购买接口的公开参数与返回类型不变。购买失败或结果未知时，请先核对库存，不要自动重复购买。
