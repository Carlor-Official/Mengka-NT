# 萌卡 NT v2.3.5

## 新增

- 等级加速任务返回独立的框架支持状态，客户端可准确区分“不支持”和“今日已完成”。

## 优化与修复

- 修复等级加速任务完成后因 `can_execute=false` 被错误显示为“暂不支持”。
- 统一网页、API 和 Node.js SDK 对 `available`、`can_execute`、`is_done` 的状态解释。

## 验证

- 后端全量 Go 测试通过。
- 前端 113 项测试与生产构建通过。

## 升级说明

- 升级前停止框架并备份 `data` 目录，完整替换框架程序和前端资源后重启。
- 保留原配置、账号数据、管理员绑定、插件数据和等级任务状态。
- 本版沿用现有等级任务 API，无需修改插件调用参数。
