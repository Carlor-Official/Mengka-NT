# 萌卡 NT v1.5.4

## 更新

本次版本完善框架版本校验，并扩展 Debug 模式下的全链路诊断日志，便于定位插件调用无响应、请求超时、签名服务异常和连接中断等问题。

### Debug 全链路诊断

- Debug 模式不再只记录个别插件 API，所有插件 action 都会记录排队、执行、路由、完成或失败阶段。
- 插件调用新增请求序号、队列等待、执行耗时、目标账号和结果摘要，可区分权限拒绝、账号不存在、WebSocket 写回失败及业务执行失败。
- MSF 请求新增发送、回包匹配、推送分发、超时、连接关闭和待处理请求数等信息。
- 签名服务新增请求构建、网络访问、HTTP 状态、响应解析和业务返回等分阶段诊断。
- HTTP 与插件 WebSocket 新增状态码、响应大小、客户端、耗时及连接异常日志。
- 普通模式保持原有日志量；仅使用 `-debug` 启动参数时输出详细诊断。

### 日志安全

- 密码、登录票据、Token、Cookie、签名缓冲、设备标识、验证码及密钥类字段会自动脱敏。
- 消息正文、图片、语音、视频、文件数据和 Base64 内容只记录类型与数量摘要，不写入详细诊断日志。
- 超长错误和响应摘要会自动截断，避免异常响应造成日志膨胀。

## 下载校验

### 框架版本校验

- 框架会携带当前版本参与签名请求，并读取萌卡 NT 官网维护的最新版本与最低可用版本策略。
- 低于最低可用版本时会停止账号会话，并明确提示“当前框架版本过低”，避免继续运行不兼容的协议请求。
- 官网策略暂时不可用时保留安全缓存与兼容回退，不影响满足版本要求的现有部署。

## 升级说明

- Windows 10/11 64 位：下载 `mengka-nt-v1.5.4-windows-amd64.zip`。
- Linux x86_64：下载 `mengka-nt-v1.5.4-linux-amd64.tar.gz`。
- Linux ARM64：下载 `mengka-nt-v1.5.4-linux-arm64.tar.gz`。
- 升级前请停止框架并备份原有 `data` 目录。完整解压新包后替换程序与前端资源，不要用空数据目录覆盖现有运行数据。
- 本次未改变插件 WebSocket API；现有 Manifest v2 插件无需重新适配。
