# 萌卡 NT v1.4.0

## 更新

- 容器管理现已同时支持 Windows Docker 与 Linux Docker，可在两种系统上统一管理框架所需的运行服务。
- 账号、节点、插件与配置数据改由 PostgreSQL 统一保存，缓存和全局统计改由 Redis 负责；首次连接时会自动把原有 SQLite 数据迁移到新存储，迁移完成后以 PostgreSQL 和 Redis 为准。
- 完善等级任务执行能力与运行数据存储，任务状态和统计信息在重启后可继续正确恢复。
- 新增 QQ 空间说说评论能力，支持文字、图片以及图文一起发送。
- 延续并完善新版插件市场、插件发布与版本同步流程。

## 修复

- 修复密码登录认证成功后没有继续发送 EMP 主票刷新包、没有完成上线注册的问题。
- 密码直登、滑块验证续登、安全验证续登和插件调用登录现在都会在真正完成换票与上线后才返回“登录成功”；失败时会明确提示并恢复离线状态。

## 升级说明

- Windows AMD64、Linux AMD64 和 Linux ARM64 用户均可直接升级到 v1.4.0。
- 升级前请先备份原有 `data` 目录。首次启用 PostgreSQL 与 Redis 时，框架会自动迁移旧数据，请勿在迁移过程中关闭程序或停止数据库容器。
- 外发包只包含可执行程序、运行数据和前端静态资源，不包含源码。
