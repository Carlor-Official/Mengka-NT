# 萌卡 NT v2.6.9

## 新增

- 新增 Pro 授权档位，移除框架对相关 API 的 QQ 等级限制；Free 保持 48 级，Plus 保持 16 级。
- 框架配置顶部新增“框架信息”卡片，展示云端确认的 UID、框架类型、授权档位、设备码和 IP。

## 优化

- 加强云核心授权校验与账号、设备绑定，完善授权续期和防降级保护。
- 管理员菜单和等级任务页面同步展示、应用云端确认的授权档位。

## 修复

- 修复无认证代理无法添加的问题：HTTP / SOCKS5 代理账号和密码改为选填，支持留空保存及编辑清空。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新成功后框架会自动重启。

本版本使用加固云核心。账号首次成功使用新核心后，不能直接降回 v2.6.8 或更早版本，请勿用旧程序覆盖升级后的安装。

Pro 移除的是框架自身的相关 API 等级门槛，接口仍受 QQ 服务端权限及业务规则约束。
