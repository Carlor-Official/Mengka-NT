# 萌卡 NT v1.8.0

## 更新

本版本统一发布 Windows、Linux amd64、Linux arm64 框架，以及桌面端和手机端管理界面。

### API 修订包

- 同步当前 1.8.0 框架 action 与官网 API 清单，补齐已恢复接口的运行时实现。
- 恢复 QQ 宠物资料、喂养、洗护、活动、好友互动和宠物 PK 等原生 API。
- 新增 QQ 农场登录 code 原生 API，供已授权插件按当前 Android QQ 会话获取农场凭据。
- QQ 宠物与 QQ 农场在官网中使用独立 API 分组；历史失效接口继续保留文档，但不会进入插件可选能力清单。
- 修复接口返回、参数校验和插件调试日志中的细节问题。

本次为 1.8.0 同版本替换包。已经下载过旧资产的用户需要重新下载并核对新的 `SHA256SUMS.txt`，替换程序文件后重启框架即可生效。

### 界面与管理

- 恢复等级加速完整页面，包含升级进度、预计升级天数、日常任务、会员倍数、额外任务和自动执行计划。
- 恢复账号自动登录、近期日志、账号心跳及运行信息。
- 完成手机端底部导航、纵向卡片、紧凑仪表和移动端任务清单，不再依赖横向滑动查看主要功能。
- Linux 与 Windows 均支持 Docker 容器管理和镜像加速。
- 应用设置迁入左侧“设置”菜单，并统一输入框、选择框、切换按钮和卡片样式。
- 插件市场优化图标与目录加载逻辑。

### 框架功能

- 支持官网账号密码与个人令牌登录，登录使用弹窗，不刷新首页内容。
- 支持批量生成与管理设备指纹，并提供占用冲突提示。
- 支持 SMTP 测试与账号异常离线邮件通知。
- Android 与 Linux 账号数据按 QQ 号和平台共同隔离。
- 在线更新支持 HTTPS、重定向和下载回退控制。

## 升级说明

### 部署说明

1. 1.8.0 不接受 1.6.2 数据升级，请使用新目录全新部署。
2. 解压对应平台的软件包，在程序目录启动 `mengka-nt`；Windows 为 `mengka-nt.exe`。
3. 首次初始化时确认协议，并使用萌卡 NT 官网账号或个人令牌绑定管理员。
4. Windows 软件包包含 Docker 安装器；Linux 使用系统 Docker Engine。
5. 部署前请核对 `SHA256SUMS.txt`，确认下载文件完整。

真实 QQ 功能仍受账号状态、客户端协议和 QQ 服务端状态影响；Linux 账号不支持等级加速。
