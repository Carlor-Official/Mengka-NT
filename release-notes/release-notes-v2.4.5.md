# 萌卡 NT v2.4.5

## 新增

- 框架向算法系统同步在线 QQ 数量，用于“在线 QQ”卡片统计。启动后立即上报，之后每 60 秒更新；同一框架实例内相同 QQ 的 Android、Linux 账号去重计算，全部离线时上报 0。
- “已卸载 · 数据已保留”的插件新增“彻底删除”入口。确认后清除该插件在框架专属目录内的保留文件、管理记录、配置和入口绑定。

## 修复

- 插件卸载后释放不再使用的独立 HTTP/HTTPS 管理入口，不再仅因保留数据继续监听端口；其他仍在使用的插件入口不受影响。
- 框架重启后，已卸载插件不会因旧运行状态恢复进程或重新占用端口。
- 已卸载插件显示为“仅保留数据”，不再误显示“安装失败”；不再提供启动或重复卸载操作。

## 升级说明

- 升级前请停止框架并备份 `data` 目录，将程序和 `public` 前端资源一起更新。
- 卸载仍默认保留数据；“彻底删除”是额外的不可撤销操作，需要明确确认。框架专属目录外的自定义数据目录及额外授权目录不会被删除，请自行备份、管理。
- 在线 QQ 上报只读取框架当前在线状态，不发起 QQ 登录或业务请求，不调整 W21、登录和票据维护行为；不同框架实例之间的相同 QQ 不做跨实例去重。
- 本次不新增或变更插件 Action 参数，不包含元宝任务实验改动。
