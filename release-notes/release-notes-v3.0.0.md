# 萌卡 NT v3.0.0

## 新增

- 新增注册卡初始化，完成注册后使用本地管理员账号登录，支持查看框架 UID 与授权权益。
- 支持 Android 手机、平板及 Linux QQ 账号管理，提供设备指纹管理与独立登录配置。
- 新增本地 IPC 插件导入、运行、配置和日志管理，支持 HTTP、正向及反向 WebSocket 插件接入。
- 补全账号登录、好友申请、群聊管理、媒体、QQ 宠物与 QQ 搭子等接口，更新官网 API 文档。

## 优化

- 重新整理管理后台与移动端布局，统一主题、图标、状态标记和账号操作入口。
- 完善等级任务面板与定时计划，自动匹配电脑 QQ 在线实例，隐藏已下线及暂不支持的任务。
- 统一插件接口的账号选择和节点范围，完善调用示例、参数说明与错误反馈。
- 完善在线更新、程序校验与重启流程，提供 Windows 和 Linux 完整安装包。

## 修复

- 修复部分账号离线后编辑协议无法保存、Linux 免扫登录失败的问题。
- 修复元宝任务材料校验、部分等级任务执行链路及完成状态判断问题。
- 修复随机设备指纹名称、在线状态圆点、账号分享头像及部分任务图标显示问题。
- 修复初始化完成后的页面跳转与入口锁定问题，并加强文件访问和插件权限检查。

## 升级说明

首次部署请下载对应系统的完整安装包，使用注册卡完成初始化。Windows 与 Linux 当前均提供 AMD64 / x86_64 安装包。

从旧版升级时，请保留原目录备份，在独立目录部署并重新初始化。已有新版实例更新前，也请停止框架并备份完整 data 目录和插件数据；程序与 public 静态资源需配套更新。

插件请按[官网 API 文档](https://mengka.net/nt/api/)检查参数和权限。账号接口使用 self_id 与 protocol_id 共同选择实例；不同协议的能力和调用限制以对应接口说明为准。
