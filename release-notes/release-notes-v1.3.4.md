# 萌卡 NT v1.3.4

## 更新

发布日期：2026-08-12

本次更新新增 App 连接地址配置，并修复多项账号稳定性与并发问题。

## 调整

### ⚠️ 重要变更

- 新增配置项 `app.serverUrl`，用于指定 App 扫码连接服务器的地址。通过反向代理或公网域名部署时，需在 `data/config.yaml` 中将其配置为实际地址（如 `https://example.com`）；纯局域网使用可不配置，将自动使用服务器局域网地址。

## 修复

### 账号稳定性

- 修复多账号高并发运行时偶发崩溃或账号被误判离线的问题。
- 修复主动断开或切换账号时误报「网络连接异常」的问题。
- 修复缓存登录在部分失败场景下误清除登录凭证、导致需要重新登录的问题。
- 修复账号信息更新后偶发连接状态异常的问题。

### 账号登录

- 修复部分账号会话维护异常、登录态无法自动恢复的问题。

### 等级任务

- 官方 QQ 机器人添加/删除好友失败时会显示具体原因，不再静默失败。
- 修复 QQ 会员福利社领券在部分场景下被无效条目中断的问题。

### 配置管理

- 修复更新设备模板或节点时偶发误报「不存在」的问题。

### 更新功能

- 修复更新完成后偶发残留临时安装包的问题。
- 首次生成的配置文件将包含 `app.serverUrl` 字段，便于直接配置。

## 优化

### 其他优化

- 优化后台实时推送在个别客户端连接卡顿时的响应速度。
- 优化消息与在线峰值统计在高并发写入时的稳定性。
