# 萌卡 NT v2.1.6

- 修复 QQ 宠物 API 请求缺少必要请求头，导致调试及插件调用返回 `msf logged-in request requires a custom reserve` 的问题。
- 修复覆盖 30 项 QQ 宠物接口共用的请求发送入口，包括宠物档案查询及缓存回退。接口名称、参数和返回格式保持不变。

## 升级说明

1. 从 v2.1.5 升级后，重新发起原有宠物 API 请求即可，无需修改调用参数。
2. 手动升级请先停止框架并备份 `data` 目录，替换主程序和 `public`，保留现有运行数据及配置。
3. 从更早版本升级，请同时查看 [v2.1.5 升级说明](release-notes-v2.1.5.md)，确认托管插件运行权限、依赖和宠物 API 参数要求。
