# 萌卡 NT v1.5.8

## 更新

本次更新以 v1.5.5、v1.5.6 为对照，重新汇总此前未完整写入更新日志、但已经进入框架前端与后端的调整，并继续合并 v1.5.7 之后的修复。此处只记录萌卡 NT 框架本身，不包含 QSign、Android APK、云真机、官网管理后台或其他独立项目。

### 商品、卡密与支付

- 用户余额、商品、订单和交易记录形成完整闭环；商品支持余额支付与在线支付，并可为指定 QQ 激活或续期。
- 在线支付改为支付窗口自动轮询订单回调，不再依赖用户点击“我已支付”；支付结果采用幂等处理，避免重复到账。
- 交易记录区分在线支付与余额支付，并单独显示支付宝、微信或余额渠道；金额符号和余额变动显示统一。
- 卡密列表将“使用用户”和“使用账号”拆分展示；卡密新增账号使用框架级账号创建流程，不要求 QQ 预先存在。
- 商品购买通知和账号掉线通知统一接入邮件配置，可优先发送到目标 QQ 邮箱，也支持账号自定义接收邮箱。

### 插件服务与调试

- 插件市场安装权限以开发者在萌卡 NT 官网选择并审核通过的 API 与事件快照为准；框架不再要求安装包包含 `mengka-plugin.json`。
- 插件下载支持 Windows、Linux amd64、Linux arm64 分别选择 Release 文件，并兼容常见压缩包格式；同一构件可以由开发者明确确认后复用。
- 新增“其他”类型插件：不下载、不自动部署，安装时直接创建正向或反向 WebSocket 服务。
- 修复自动部署插件时工作目录、入口文件和启动参数不一致导致 `exit status 23` 的问题，并将通用部署规则用于后续新插件。
- Debug 模式补充 WebSocket 收发、事件分发、插件 action、签名、MSF 请求和超时关联信息，同时继续隐藏 Token、签名缓冲和敏感字段。
- 公开 Node.js SDK 与框架当前 85 个 action 保持同步；权限是否可用仍以安装时冻结的官网审核快照为准。

### 安装、初始化与在线更新

- 首次部署改为浏览器两步初始化：先阅读萌卡 NT 使用协议，再使用萌卡 NT 官网个人令牌绑定管理员；完成后初始化入口自动锁定。
- 管理员身份以萌卡 NT 官网用户为主控制端，支持官网账号密码或个人令牌登录，不再额外生成一套独立管理员资料。
- 首次自动安装 PostgreSQL、Redis、FFmpeg 后会等待容器可用并自动重启相关流程，减少“已安装但未启动”的误报。
- 框架启动会读取官网最低版本策略；低于最低版本时进入专用更新页，可直接执行在线更新或前往 GitHub 手动更新。
- 在线更新按钮改用下载并安装语义的图标，更新流程与普通刷新操作明确区分。

### PC 与手机端界面

- 管理端和 user 端统一完成 PC、平板和手机布局复检；手机端按 App 交互设计，不再只是桌面表格的竖屏压缩。
- 手机端使用底部导航、信息卡片、底部表单和触控友好的操作区；账号、用户、商品、卡密、支付、指纹、插件与设置页面统一适配。
- 清理表格外层空壳、重复卡片和“框套框”结构，修复弹窗底部按钮被导航遮挡、内容横向溢出、栏位错位和操作按钮贴边。
- 概览热力图在窄屏下可横向查看完整数据，长表单和选择器限制在可视区域内滚动。
- user 端右上角展示用户账号而不是当前 QQ，用户资料、余额和安全设置入口集中到用户头像菜单。

## 修复

### 用户系统与账号流程

- user 端开放注册、邮箱验证码注册、找回密码、修改密码、邮箱绑定与双重验证换绑；框架未配置 SMTP 时会明确提示联系管理员。
- 管理端可以开启或关闭整个 user 端、控制注册与邮箱验证，并支持用户封禁、解禁、密码修改和余额加减；账号资料编辑与余额调整相互独立。
- 修复删除 QQ 账号误删 user 端用户的严重问题；用户资料、余额、订单和交易记录不再随 QQ 删除。
- 重新梳理 QQ 添加、找回、激活和续费：框架中已有 QQ 必须先找回同步，新 QQ 可以先保存，再通过卡密、余额商品或在线支付激活。
- user 端账号列表与管理端统一为同一套信息结构和登录逻辑，缓存登录后会重新获取账号状态，避免继续使用过期鉴权数据。
- user 端新增指纹菜单，只显示空闲指纹并允许新增；已被其他 QQ 使用的指纹不会泄露给普通用户。

### 登录、消息与设备稳定性

- 设备指纹改为不可编辑、可一键生成，并在后端强制执行“一份指纹只分配给一个 QQ”；管理端、user 端、卡密和插件接口不能绕过。
- 更换指纹或关键登录配置时清理旧登录缓存；缓存登录、换票和重新注册失败时恢复一致状态，降低半更新登录态引发的 W21/S26 风险。
- 修复好友私聊在身份缓存缺失时返回 `wait serverResp timeout` 的问题，好友消息与好友图片统一使用按需身份刷新流程。
- 修复同一条 QQ 推送被重复下发、导致插件回复两次的问题；按账号、会话和协议消息标识并发去重，不按文本误判。
- QQ 自带表情支持 `[bq<表情ID>]`，并继续兼容 Unicode Emoji、群聊、私聊和组合消息。
- 在线时长按真实上线时间计算；账号缓存登录后会刷新最新状态再进行接口鉴权。

## 升级说明

- v1.5.5、v1.5.6、v1.5.7 均可直接升级到 v1.5.8；升级前请停止框架并备份现有 `data` 目录。
- 完整解压新包后替换程序与前端资源，不要用新包中的空数据覆盖原有运行数据；数据库兼容迁移会由框架启动时执行。
- Windows 10/11 64 位：下载 `mengka-nt-v1.5.8-windows-amd64.zip`。
- Linux x86_64：下载 `mengka-nt-v1.5.8-linux-amd64.tar.gz`。
- Linux ARM64：下载 `mengka-nt-v1.5.8-linux-arm64.tar.gz`。
- 本 Release 只提供上述三个框架外发包，不包含 Android APK、QSign 服务或其他独立项目附件。
