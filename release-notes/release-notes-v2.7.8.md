# 萌卡 NT v2.7.8

## 优化

- 元宝任务执行中及等待 QQ 确认时显示进度条和已用时。
- 明确区分等待验证、执行中、等待 QQ 确认和执行停止，并展示停止阶段。
- 元宝验证改为打开官方页面，关闭提示后可继续打开同一次验证入口。

## 新增

- 支持取消尚未提交图片任务的当前元宝验证，取消后恢复待完成，无需等待原验证过期。

## 修复

- 修复元宝活动设备信息部分成功响应被误判的问题。
- 修复关闭验证窗口后无法再次打开验证入口的问题。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新完成后框架会自动重启。

验证通过不等于任务完成，以 QQ 返回的完成状态为准。历史执行已停止或结果不明的记录不会自动清除或重跑。
