# 萌卡 NT v1.4.5

## 新增

- 设置 → 应用新增“数据库方案”，可以查看当前实际使用的方案，并选择自动适配、PostgreSQL + Redis 或 SQLite + 进程内缓存。
- 网页登录用户端新增“账号”页面，仅显示当前登录的 QQ，可独立修改该账号的密码、登录协议、设备指纹和登录节点，不会影响其他账号。

## 修复

- 修复框架通过域名反代、HTTPS 或公网 IP 访问时，令牌页面错误显示内网地址，导致萌卡 APP 扫码后无法绑定的问题。
- 修复数据库方案由环境配置固定时，页面仍允许选择不可用方案的问题；现在会显示当前限制原因。
- 修复公开站点设置接口返回管理端运行信息的问题。

## 优化

- 数据库方案保存后会明确提示需要重启生效，并显示“待重启生效”状态，避免误以为切换失败。
- 自动方案会根据当前设备的容器运行能力选择合适的数据模式；无法使用 Docker 的系统仍可继续使用本地数据模式。
- 网页登录的账号配置由后端强制限定为当前 QQ，即使手动修改请求也无法查看或更改其他账号。

## 升级说明

- 直接替换程序文件即可，原有 `data` 目录请继续保留。
- 切换数据库方案后需要重启后端。不同方案各自保留原有数据，不会自动删除或覆盖另一套数据库。
- 使用宝塔、Nginx 等反向代理时，请继续正确转发访问域名和协议，令牌页面会自动使用用户当前访问的公网地址。
