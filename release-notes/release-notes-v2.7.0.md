# 萌卡 NT v2.7.0

## 新增

- 支持授权变更在线通知。算法后台调整授权档位或封禁状态后，在线框架收到通知即重新鉴权并同步云配置，不再仅依赖定时续期。

## 优化

- 隐藏更新弹窗右侧滚动条，保留鼠标滚轮、触摸滑动和快速滑到底部功能。
- 完善重启前的辅助进程退出流程，重启失败时恢复崩溃日志监控。

## 修复

- 修复 Linux 在线更新或重启后，崩溃日志辅助进程未回收、逐渐积累僵尸进程的问题。
- 新程序启动时接管同一主进程原地升级遗留的子进程，保留正常插件的退出状态和崩溃日志记录。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新成功后框架会自动重启。

授权变更通知需要配套算法服务支持。离线或网络异常时无法即时接收通知，恢复连接后自动同步；原定时续期机制继续保留。

已启用加固云核心的账号不能直接回退至 v2.6.8 或更早版本。此次更新不会修改原有账号、设备指纹或缓存登录设置。
