# 萌卡 NT v2.3.4

## 新增

- 等级加速新增“来元宝P图一次”任务，执行后以 QQ 返回状态确认完成结果。

## 优化与修复

- 统一等级任务查询、计划与执行状态，插件继续使用现有等级任务 API。
- 优化小游戏擂台及已完成任务判定，避免重复执行。
- “去看免费小说”仍暂不支持。

## 验证

- 后端全量测试、前端测试与生产构建、Node.js SDK 测试均通过。
- Windows AMD64、Linux AMD64、Linux ARM64 外发包均已完成隔离启动验证。

## 升级说明

- 升级前停止框架并备份 `data` 目录，完整替换框架程序和前端资源后重启。
- 保留原配置、账号数据、管理员绑定、插件数据和等级任务状态。
- 本版沿用现有等级任务 API，无需修改插件调用参数。
