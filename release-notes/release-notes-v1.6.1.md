# 萌卡 NT v1.6.1

v1.6.1 重点完善账号连接稳定性和“电脑 QQ 在线”等级任务。框架会更稳妥地处理签名服务瞬时波动、心跳异常与 MSF 节点拒绝，同时把电脑在线任务改为由当前已登录的安卓协议账号自动确认并全程展示进度。

## 账号连接稳定性

- 签名请求遇到连接重置、连接关闭、DNS、TLS 或短时网络异常时，会使用全新连接自动重试，降低失效长连接造成的偶发签名失败。
- 心跳所需签名暂时不可用时，不再立即关闭仍然正常的 QQ 连接；框架保留当前会话并按 15 秒间隔继续轮询恢复。
- 普通心跳异常会先进行有限次数重试；W21、S26、框架版本过低等明确拒绝仍立即进入原有下线与重新登录流程。
- QQ 服务端明确拒绝当前会话后，缓存重连会重新校验最新账号状态，并优先切换到不同的 MSF 节点完成鉴权，避免持续命中同一异常节点。
- 收紧重连、心跳和登录状态之间的并发处理，避免一次失败的重连尝试覆盖仍在进行的恢复流程。

## 电脑 QQ 在线任务

- 等级任务新增完整的电脑 QQ 在线执行链路：账号在线且开启任务后，框架会启动独立 Linux QQ 运行环境，并由当前已登录的安卓协议账号自动确认电脑登录。
- “下次记住此设备”和“电脑在线任务”拆分为两个独立开关，由用户自行决定是否保存设备授权。
- 前端会连续展示排队、启动、自动确认、在线计时、任务确认和完成状态；在线时长按秒实时更新。
- 在线满 2 小时并确认任务完成后，框架会自动下线电脑 QQ、停止对应运行环境并释放资源。
- 关闭任务会立即清理旧的二维码、验证和在线状态；升级前遗留的手动扫码提示会自动转换为框架授权状态，不再要求用户重复扫码。
- 管理端与 user 端使用相同的任务状态和控制逻辑，并完成手机端操作区布局适配。

## SDK 同步

- Node.js 正向与反向 SDK 的便捷方法增至 119 个。
- 补充 `generate_device_profile` 与 `set_group_card` 便捷方法，分别用于按框架规则创建随机设备指纹、修改或清空群成员名片。
- 本次没有扩大插件授权范围；插件实际可调用的 API 与事件仍以萌卡 NT 官网审核并随安装冻结的权限快照为准。

## 升级说明

1. 停止旧版框架并备份现有 `data` 目录。
2. 下载对应系统的 v1.6.1 外发包，完整替换程序和 `public` 前端资源。
3. 保留原有业务数据、配置、插件与运行目录，不要使用新包中的初始化数据覆盖现有数据。
4. 启动框架后，检查账号在线状态、插件连接和等级任务页面是否正常。
