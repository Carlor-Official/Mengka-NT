# 萌卡 NT v1.3.8

## 更新

### 群语音稳定性

- 修复插件发送群语音时可能导致整个后端退出的问题。
- 遇到异常音频时会返回明确失败信息，不再影响其他账号与插件继续运行。

### 插件市场与开发者投稿

- 插件市场现在可以同步官网“插件市场”分类中已审核发布的插件文章。
- 开发者发布插件时可以直接使用文章表单填写插件名称、版本、支持平台和下载地址，不再需要在正文中手写复杂配置。
- 插件介绍正文可继续使用图文与 Markdown 排版，审核通过后自动进入框架插件市场。
- 插件更新重新提交并审核后，框架会同步最新版本与最后更新时间。

### 账号登录体验

- 缓存登录增加超时保护，网络或节点异常时不会一直停留在“正在检查缓存”。
- 登录等待界面新增“取消登录”，可直接终止本次登录并恢复账号状态。
- 登录失败时会区分超时、主动取消和后端返回错误，方便快速判断原因。

### 等级任务

- 等级加速任务增加 QQ 16 级使用条件，后台和网页登录页面都会显示当前等级与限制提示。
- 未达到条件时会停用补挂、批量选择和自动执行计划，达到 16 级后即可正常使用。

### 宠物功能

- 完善好友宠物资料、喂食、洗护、访问以及宠物 PK 相关数据处理。
- 修复部分账号获取 PK 好友列表为空的问题，并补全好友宠物与 PK 状态信息。
- 优化食物、洗护用品和宠物信息的识别，调用时可继续使用对用户更直观的名称或 QQ 号。

## 升级说明

1. 停止正在运行的萌卡 NT，并完整备份原安装目录中的 `data` 目录。
2. 根据系统和 CPU 架构下载对应外发包并解压。
3. 替换程序文件和 `public` 静态资源，同时更新包内的 `data/protocol.json`、`init.sql`、`migrations.sql`、`policy.bin`。
4. 保留原有数据库、账号配置、登录缓存和插件数据，再启动新版本。
5. 启动后可在“关于”页面确认版本号为 `v1.3.8`。

Windows 用户请选择 `windows-amd64.zip`；常见 Linux 服务器请选择 `linux-amd64.tar.gz`；ARM 服务器请选择 `linux-arm64.tar.gz`。
