# 萌卡NT v3.0.5

## 新增

- 新增账号列表排序按钮，可按 QQ 号切换升序、降序和默认顺序。
- 新增外部访问地址设置，支持配置域名、IP、HTTP／HTTPS 及端口，便于使用反向代理访问框架和插件门户。

## 优化

- 合并插件服务与 IPC 插件管理页面，增加“全部”和“IPC 导入”分类，点击“插件导入”即可上传插件包。
- 迁移码有效期调整为 24 小时。申请后可在删除旧框架或重装系统后，从全新部署恢复，无需原框架再次上线确认。
- 完善验证端人工恢复入口，管理员核验身份并填写原因后，可为原用户生成 24 小时恢复码。
- 迁移或恢复时保留原 UID、Free 永久权益及 Plus／Pro 各自到期时间，无需重新使用注册卡；完成后旧部署授权立即失效。
- 同步调整框架内 API 调试、官网接口文档及 SDK 的接口可用范围。

## 修复

- 修复账号列表长按拖动时，误触发文字和头像选中的问题。
- 修复 Linux 下以 root 运行框架时，部分安装目录导致 IPC 插件无法导入或启动的问题。
- 修复 HTTPS 反向代理下，插件门户访问地址和协议识别不一致导致的注册、登录及会话保持异常。

## 升级说明

升级前请备份完整 data 目录与插件数据。手动升级时，请先停止框架，再替换程序和配套 public 静态资源。保留原 data 目录，无需重新使用注册卡。

部署迁移与人工恢复仅保留 UID 和授权权益，QQ 账号及插件业务数据需另行备份、迁移；全新初始化时需重新设置本地管理员。

QQ 宠物公开接口统一使用 `qqpet_operation` 支持的通用业务。其余 `qqpet_*`、`qmate_*` 接口停止对外调用，文档入口保留并标记“已移除”。

以下接口同时停止对外调用：`send_group_temp_msg`、`send_friend_request`、`send_group_join_request`（含 `join_group` 别名）、`upload_group_file`、`upload_private_file`。相关插件请同步适配。

使用用户插件时，请同步更新对应的适配版本。
