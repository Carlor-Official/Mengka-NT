# 萌卡 NT v1.9.1

本版本继续以 Linux QQ 原生协议为核心，重点修复 Linux 账号重复登录链路，并优化等级加速任务操作。

## 核心更新

- 修复同一 QQ 同时存在 Android 与 Linux 协议记录时的平台识别问题，账号状态、运行环境和操作入口按协议独立展示。
- 修复 Linux QQ 首次扫码成功后，下线再次登录可能错误进入密码登录的问题；Linux 登录继续使用原生二维码链路。
- 优化等级加速项目区，支持项目行开关、完成状态、单项选择、多选与批量控制，整体界面继续沿用萌卡 NT 现有设计。

## 升级说明

升级前请完整备份原目录中的 `data`。停止旧版本后替换程序文件和 `public` 前端资源，并保留原有数据库与管理员配置。

外发包不包含数据库、管理员配置、日志、源码、密钥或 Git 元数据。实际 QQ 功能仍受账号状态和 QQ 服务端状态影响。
