# 萌卡 NT v1.3.10

## 更新

- 云端插件市场已适配官网新版发布与审核流程，开发者提交的新插件和版本更新可正常同步到框架。
- 优化插件详情展示，旧版文章中用于系统识别的配置内容不会再混入用户看到的详情页。
- 新增插件 WebUI SDK，插件可以按照统一规范把自己的网页后台接入框架管理界面。
- 官网发布插件教程和 API 文档已同步更新，开发者可以从教程快捷进入发布与管理页面。

## 升级说明

- Windows 与 Linux 用户可以直接升级，本版本不会主动删除现有账号、配置、插件或运行数据。
- 新旧两种插件发布格式均继续兼容，已上架插件不需要重新发布。
- 需要接入插件网页后台的开发者，可查看公开仓库中的 `sdk/plugin-web` 接入说明和示例清单。
