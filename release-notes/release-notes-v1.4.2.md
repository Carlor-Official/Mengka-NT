# 萌卡 NT v1.4.2

## 更新

本版本重点修复新版插件市场的图片展示，并补全等级任务与空间评论相关体验。

- 修复通过新版发布流程上架的插件 Logo 在框架插件市场中无法显示的问题。
- 插件 Logo 统一由框架加载，兼容 HTTPS、反向代理和不同域名部署环境。
- 补全“参与盲盒签并成功发布空间”等级任务，支持正常检查与补挂。
- 优化空间图文评论的图片处理，兼容更多图片返回格式。
- 官网 API 文档同步补充空间评论接口，并完成全部接口页面校验。

## 升级说明

- 可直接使用框架内置在线更新升级。
- 手动升级时请先停止旧程序，保留原有 `data` 目录，再覆盖程序及前端文件。
- Windows 使用 `windows-amd64` 压缩包；常见 Linux 服务器使用 `linux-amd64`，ARM 服务器使用 `linux-arm64`。
