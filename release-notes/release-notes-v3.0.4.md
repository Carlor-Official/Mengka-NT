# 萌卡NT v3.0.4

## 新增

- 新增账号列表长按拖动排序，调整后的顺序可保存。
- 新增在线部署迁移与管理员人工恢复，迁移后保留原 UID 和 Plus／Pro 权益到期时间，旧部署授权同时失效。
- 新增 Linux 本地插件自动降权运行，框架以 root 启动时，由框架自动准备独立的非 root 插件运行环境。
- 补充消息发送确认、群管理员变更、群名片变更、群名称变更、群头衔变更、群精华消息变更、群系统提示、消息回应、戳一戳、输入状态及连接状态、心跳等事件。
- 提供适配新版 API、事件和 IPC 的 JavaScript／TypeScript SDK，配套调用示例与接入文档。

## 优化

- 账号列表默认按添加顺序排列，新添加的账号置顶；登录、离线和数据刷新不再改变排列顺序。
- 优化验证端用户列表、用户详情和权益调整，减少重复查询与刷新等待。
- 优化验证端页面轮询和保存后的数据同步，减少重复请求，避免旧响应覆盖正在编辑的内容。
- 同步框架内 API 调试目录、参数说明与官网接口文档。
- 补充官网事件分类、字段说明、适用范围及 SDK 接入说明。

## 修复

- 修复“更新已完成”弹窗确认后，再次访问仍重复出现的问题。
- 修复电脑在线任务与账号页免扫登录的授权参数不一致问题。
- 修复名片点赞事件的转发链路，并补全相关事件字段说明。
- 修复批量登录时，签名调用受到额外频率或并发配额限制而被拒绝的问题。
- 移除元宝及插件调用中额外的数量和并发配额限制。
- 修复多个合法响应同时到达时，可能被误判为响应过大的问题。

## 升级说明

升级前请备份完整 data 目录与插件数据。手动升级时，请先停止框架，再替换程序和配套 public 静态资源。保留原 data 目录，无需重新使用注册卡。

Windows 提供 AMD64 / x86_64 安装包；Linux 提供 AMD64 / x86_64 和 ARM64 / AArch64 安装包。部署迁移保留授权权益，业务数据和插件数据仍需单独备份、搬迁。
