# 萌卡 NT v2.7.9

## 优化

- 完善手动更新和自动更新后的重启与账号恢复流程。
- 优化元宝任务状态刷新，任务结束后清理旧验证入口和用时显示。

## 修复

- 修复元宝任务终止或升级后残留暂停状态，导致无法再次执行的问题。
- 修复部分临时服务异常导致更新后仍需手动重启的问题。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新完成后框架会自动重启，账号按原有登录设置恢复。

已终止的元宝任务会恢复待完成，可手动重新执行；正在执行、等待有效验证或等待 QQ 确认的任务继续按当前流程处理。恢复待完成不代表任务成功，最终以 QQ 返回的完成状态为准。
