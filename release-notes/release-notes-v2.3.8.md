# 萌卡 NT v2.3.8

## 新增

- 新增长时间等级任务的后台执行状态查询接口。

## 优化与修复

- 修复“去看免费小说”执行约两分钟后被网关返回 504 的问题。
- 免费小说任务先返回执行编号，后台持续执行 QQ 阅读心跳，前端轮询完成状态并刷新任务面板。
- 页面提示明确说明任务可在后台继续执行，关闭等级加速页面不会取消已提交任务。

## 验证

- 后端全量 Go 测试通过。

- `git diff --check` 通过。

- 升级前停止框架并备份 `data` 目录，完整替换框架程序和前端资源后重启。
