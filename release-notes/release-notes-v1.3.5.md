# 萌卡 NT v1.3.5

## 新增

### 插件开发接口更新（2026 年 8 月 15 日）

- 新增宠物资料、状态、食物、洗护、学习、打工、冒险、好友互动和 PK 等插件能力。
- 开发者只需要填写食物名称、洗护用品名称、活动类型、课程或岗位名称等直观参数，其余信息由框架自动查询和处理。
- 活动状态、当前阶段和可用选项会以清晰的数据返回，官方拒绝原因也会直接反馈给插件。
- 对购买、喂食、洗护、活动启动和结算等操作不会在超时后自动重复执行，减少重复操作风险。
- 正向与反向 WebSocket SDK、开发者平台接口列表和官网文档已同步更新。

### 安装、更新和卸载更完整

- 系统会自动识别当前是 Windows 还是 Linux，并选择适合当前设备的插件版本。
- 安装时可以直接查看下载进度、已下载大小和当前状态。
- 切换到其他页面后，安装任务仍会继续；返回插件市场即可继续查看进度和结果。
- 已安装插件可以检查更新、重新安装或卸载；即使插件版本号没有变化，也可以获取开发者重新发布的内容。
- 卸载时会同时停止插件，并清理由插件市场创建的相关服务和安装文件。
- 新增操作日志，可查看下载、安装、更新、卸载和失败原因，排查问题更方便。

## 修复

### Windows 安装修复（2026 年 8 月 15 日）

- 修复从插件市场安装 B站综合插件后，创建服务提示“运行入口不存在”的问题。
- 修复 Windows 插件后台无法跟随框架设置自动启动的问题。
- 修复关闭 Windows 框架窗口后插件仍留在后台、重新启动框架时进程重复拉起的问题。
- 如果已经下载过此前的 1.3.5 Windows 安装包，请重新下载 Windows x86-64 包并覆盖更新；Linux 用户不受影响。

发布日期：2026 年 8 月 15 日

这次更新重点完善了插件的获取、安装和管理体验。现在可以直接在萌卡 NT 后台浏览云端插件，从安装到更新、打开插件后台、查看日志和卸载，都能在同一处完成。

### 问题修复与体验改进

- 修复插件市场偶尔提示“同步云端失败”的问题。
- 修复插件图标无法显示或尺寸异常的问题。
- 修复安装按钮点击后恢复原状、插件没有真正完成安装或启动的问题。
- 修复通过域名访问并开启 HTTPS 后，后台实时状态可能无法显示的问题。
- 优化插件市场、详情页、按钮和卡片样式，使其与萌卡 NT 后台整体风格保持一致。

## 更新

### 全新的插件市场

- 插件页面现在分为“服务列表”“插件市场”和“操作日志”，查找和管理更清晰。
- 插件市场提供“热门插件”和“全部插件”分类，并采用更直观的双列卡片布局。
- 插件图标会根据卡片空间自动缩放，不再出现图片撑开页面的情况。
- 详情页支持更丰富的图文排版，开发者可以提供更完整的功能介绍、使用说明和部署教程。

### 插件使用更方便

- 从市场安装的插件可以直接在萌卡 NT 中快捷添加服务，无需重复填写连接信息。
- 支持网页后台的插件，会在插件市场卡片中显示“打开后台”；没有网页后台的插件不会显示无效入口。
- 插件网页可以融入萌卡 NT 后台使用，减少在多个地址之间来回切换。
- 服务列表保持专注于连接和运行状态，插件后台入口统一放在插件市场中。

## 优化

### 下载体验优化

- GitHub 插件下载会自动尝试可用线路，遇到线路速度慢或下载不完整时会切换后重试。
- 支持开发者分别提供 Windows、Linux 下载地址，兼容常见直链、代码托管平台及网盘分享地址。
- 修复部分大文件下载到一半后提示“插件包下载不完整”的问题。
- 插件统一安装到 `data/plugin-market`，框架目录更加整洁，也便于备份和迁移。

## 升级说明

- 建议升级前先停止萌卡 NT，并备份现有 `data` 目录。
- 可以使用框架内的在线更新，也可以在本页面下载对应系统的完整安装包。
- 手动升级时请覆盖程序和网页文件，不要删除原有 `data` 目录中的账号、配置和运行数据。
- 本次提供 Windows x86-64、Linux x86-64 和 Linux ARM64 三种安装包，请按服务器系统选择。
