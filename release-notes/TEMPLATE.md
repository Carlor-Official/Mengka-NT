# 更新日志模板

发行标题统一为“萌卡 NT v版本号”。正文保留一个相同的一级标题，按实际内容使用新增、优化、修复、调整或更新等二级分类；不填写空分类。复杂主题可以使用三级标题。升级步骤放在“升级说明”中。

```markdown
# 萌卡 NT vX.Y.Z

## 新增

- 新增功能。

## 优化

- 使用体验优化。

## 修复

- 问题修复。

## 调整

- 行为或兼容性调整。

## 升级说明

按本版实际要求填写升级方法。
```

只记录本版本实际变更，不把后续版本的行为补写到历史日志。校验值、旧版本必要的验证与兼容性说明应保留，格式调整不改变历史发行包、标签或发布时间。
