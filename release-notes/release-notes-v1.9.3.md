# 萌卡 NT v1.9.3

本版本继续以 Linux QQ 原生协议为核心，重点提升扫码确认、上线注册与重新登录过程的稳定性。

## 核心更新

- 修复 Linux QQ 扫码确认后可能出现 `msf tcp disconnected`、停留在待确认或最终登录失败的问题。
- 修复旧会话离线通知可能打断新扫码会话的问题，提升重复扫码与重新登录的成功率。
- 恢复并统一经过验证的 Linux 原生上线链路，避免扫码成功后注册失败。
- 保持 Android 与 Linux 两套登录流程独立，Linux 缓存失效后继续进入二维码登录，不会错误切换为密码登录。

## 升级说明

升级前请完整备份原目录中的 `data`。停止旧版本后替换程序文件和 `public` 前端资源，并保留原有数据库与管理员配置。

外发包不包含数据库、管理员配置、日志、源码、密钥或 Git 元数据。实际 QQ 功能仍受账号状态和 QQ 服务端状态影响。
