# 萌卡 NT v1.7.0

## 更新

v1.7.0 对管理端、初始化流程和扩展管理进行了整体更新。在保留旧版布局与操作习惯的基础上，重新整合新版功能，补齐主题、账号、指纹、插件、通知和在线更新等常用能力。

### 账号、指纹与通知

- Android 与 Linux QQ 类型统一收纳到账号入口，账号列表支持按账号类型与登录状态组合筛选。
- 账号设置整合到账号页面，可集中管理隐私模式、缓存登录、静默模式和离线账号清理。
- 修复清空账号缓存时的请求错误，并优化账号登录、二维码验证和相关弹窗的排版与提示。
- 指纹页面新增一键生成，可一次随机创建 1–10 套完整设备指纹，并按连续序号自动命名。
- 指纹列表新增多选、筛选结果全选和批量删除，单次最多处理 100 项。
- 新增账号掉线邮件提醒，支持统一配置发件服务、发送测试邮件，并为每个账号单独设置通知开关和收件邮箱。

## 新增

### 管理端与主题

- 管理端恢复旧版导航结构和页面布局，并将 1.7.0 的功能入口、数据卡片和操作内容统一纳入同一套界面。
- 新增 8 套主题色，全部支持明亮与暗夜模式；主题偏好会自动保存，切换后全站按钮、输入框、选择框、卡片和状态色同步更新。
- 统一各页面的表单、筛选器、切换按钮、弹窗与卡片样式，并完善桌面端和移动端排版。
- 侧边菜单与页面内容改为独立滚动，菜单滚动条不再外显，二级菜单补充展开、收起和当前页面高亮效果。
- 概览页恢复经典数据面板，新增账号状态、今日消息、年度消息活跃图、24 小时在线记录、运行状态和实时流量展示。
- 首页登录改为页面内弹窗，不再跳转或刷新首页内容；刷新、返回首页和切换管理页面时会保持有效登录状态。

### 初始化、应用设置与在线更新

- 重新整理首次初始化流程，依次完成使用声明、管理员绑定和运行环境确认。
- 初始化时会检测旧版本运行数据，由用户明确选择接管旧数据、创建独立新环境，或在备份成功后清理旧数据。
- 应用设置补齐站点标题、版权信息、备案号、页面水印和邮件通知配置。
- 恢复在线更新功能，可在管理端检查新版本、查看更新日志、下载更新并查看处理进度。
- 新增最低版本提示页；当前版本低于最低使用要求时，会显示需要更新的版本信息和下载入口。
- 重新设计关于页面，集中展示版本、框架能力和项目入口。

## 优化

### 插件与运行管理

- 重做插件市场列表和详情展示，支持名称与分类筛选、热门与全部插件切换、版本信息、更新日志和安装进度。
- 优化插件图标尺寸、加载和失败回退，改善远端市场响应较慢时的页面体验。
- 补全插件服务列表与操作日志，可查看安装、更新、下载、解压和失败记录。
- 插件服务支持正向与反向 WebSocket 配置，并保留多实例、节点和运行状态管理。
- 容器、账号和应用相关配置回到各自所属页面，减少重复设置入口。

## 优化与修复

### 修复与体验优化

- 修复部分主题下文字、边框和状态色对比不足的问题。
- 修复插件分类菜单在不同页面仍停留在服务列表高亮的问题。
- 修复插件市场图标空白、重复加载以及市场读取超时时的异常提示问题。
- 修复部分账号筛选、缓存清理、登录验证和二维码边框位置异常。
- 优化顶部账号信息、登录弹窗、插件卡片、设置页面和空数据状态的对齐与响应式布局。

## 升级说明

1. 升级前请备份现有框架数据与配置。
2. 可在管理端使用在线更新，或下载对应系统和架构的 v1.7.0 运行包完成升级。
3. 首次启动后按照网页初始化向导完成管理员绑定，并在运行环境检查页选择旧数据处理方式。
4. 默认推荐创建 1.7.0 独立新环境；该方式会保留旧数据，便于确认新版本运行正常后再另行处理。
5. 如需沿用 1.6.2 数据，请选择“接管旧数据”并等待页面完成兼容处理；处理中不要手动删除旧数据。
6. 只有在确认备份可用后，才选择“备份后清理旧数据”。
7. Linux QQ 当前仅保留前端扩展入口，本版本不包含对应后端运行能力。
8. 升级完成后请检查账号状态、插件连接、主题显示和邮件通知配置。
