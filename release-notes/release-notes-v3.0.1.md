# 萌卡 NT v3.0.1

## 优化

- 优化注册卡验证时的断线恢复与等待提示，网络短暂中断后自动继续验证。
- 完善纯 IP、域名、HTTP、HTTPS 及反向代理部署的初始化兼容性。
- 更新 API 调试页面的官网文档链接。

## 修复

- 修复部分部署环境注册时提示“cross-origin request rejected”的问题。
- 修复反向代理访问后台时，在后台与“服务恢复”页面之间循环跳转的问题。
- 修正连接检查页面固定显示 502 的误导提示，登录状态检查失败时支持手动重试。
- 修复注册请求中断后，初始化页面持续等待、无法继续验证的问题。
- 修复网络异常时重复提交可能造成的注册恢复问题，继续使用原实例凭据确认注册结果。

## 升级说明

从 3.0.0 升级时，请先停止框架并备份完整 data 目录与插件数据，再替换程序和配套 public 静态资源。保留原 data 目录，无需重新使用注册卡。

首次部署请下载对应系统的完整安装包，使用注册卡完成初始化。Windows 与 Linux 均提供 AMD64 / x86_64 安装包。
