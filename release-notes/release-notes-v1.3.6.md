# 萌卡 NT v1.3.6

## 更新

### 网页登录与账号管理

- 新增“网页登录”功能，管理员可以设置全局开关，也可以为单个 QQ 账号单独开启或关闭。
- 网页登录使用 QQ 号和该账号已缓存的 QQ 密码，登录后只显示当前 QQ 的运行信息和数据。
- 支持为有缓存的账号开启自动登录，框架重启后会自动尝试恢复上线。
- 优化账号设置页面的状态显示和操作反馈。

### 等级任务

- 等级任务升级为框架独立菜单，可按 QQ 账号查看今日加速、会员加速、日常任务和额外任务。
- 支持全选、多选和批量补挂，并可保存每日自动执行计划。
- 付费任务会明确标注为“付费任务”，只有当前确实无法执行的项目才显示“暂不支持”。
- 修复部分任务补挂后状态未及时更新的问题。

### 插件 API 与 SDK

- 完善 QQ 宠物接口，补齐宠物资料、食物和洗护用品目录、购买、喂食、洗护、活动、结算及好友互动能力。
- 宠物资料会返回 `pet_id`，购买、喂食和洗护可使用目录中的名称或 ID。
- Bot 信息与 Bot 列表增加 QQ 会员状态。
- 新增群聊可领取红包查询，并同步正向、反向 WebSocket SDK。
- 官方 Node.js SDK 统一放在仓库 `sdk/nodejs` 目录，不再按版本号拆分目录。

### 稳定性与体验

- 改进框架重启后的账号恢复与状态统计，减少 Windows 环境重启后出现的重复异常提示。
- 增加更完整的启动和异常日志，发生问题时更容易定位原因。
- 优化账号范围内的概览数据，避免网页登录用户看到其他账号的统计。
- 更新前端依赖补丁，并同步全部 API 文档与调用示例。

## 升级说明

1. 停止正在运行的萌卡 NT，并完整备份原安装目录中的 `data` 目录。
2. 根据系统和 CPU 架构下载对应外发包并解压。
3. 替换程序文件和 `public` 静态资源，同时更新包内的 `data/protocol.json`、`init.sql`、`migrations.sql`、`policy.bin`。
4. 保留原有数据库、账号配置、登录缓存和插件数据，再启动新版本。
5. 启动后确认账号状态、网页登录设置、等级任务和插件服务均正常。

Windows 用户请选择 `windows-amd64.zip`；常见 Linux 服务器请选择 `linux-amd64.tar.gz`；ARM 服务器请选择 `linux-arm64.tar.gz`。
