# 萌卡 NT v2.8.0

## 优化

- 完善元宝任务准备和登录失败时的提示，展示对应处理步骤。
- 补充账号日志中的元宝任务失败原因，便于定位问题。

## 修复

- 修复尚未完成元宝首次登录的账号被误报为接口错误的问题。
- 修复材料准备失败时仍提示等待 QQ 确认，与实际执行阶段不一致的问题。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新完成后框架会自动重启，账号按原有登录设置恢复。

如提示尚未完成元宝注册，请使用同一个 QQ 在官方元宝 App 完成首次登录，再返回框架执行任务；无需更换 QQ 指纹或清除缓存。任务是否完成仍以 QQ 返回的状态为准。
