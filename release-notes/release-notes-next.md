# 萌卡 NT v2.7.7

## 新增

- 完善 Android 9.2.70 手机、平板的元宝任务支持。

## 优化

- 元宝任务完成后自动刷新 QQ 任务状态，及时展示完成结果。
- 添加、编辑插件服务弹窗加宽，与添加账号弹窗保持一致，并优化手机端布局。

## 修复

- 修复插件服务令牌重新生成按钮位置异常及弹窗横向溢出的问题。
- 改善设备指纹生成遇到系统资源不足时的错误提示。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新完成后框架会自动重启。

原有账号的协议、指纹和登录身份保持不变。元宝任务如要求官方身份验证，请完成当前验证后等待续接；历史“结果待核对”记录不会自动重复提交。
