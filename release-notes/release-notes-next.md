# 萌卡 NT v2.7.4

## 新增

- 账号编辑新增“刷新指纹”按钮，离线并确认后可为当前账号及协议生成新的设备指纹；原“清空缓存”功能保留。

## 调整

- 设备指纹改为由框架自动管理，移除独立设备指纹页面及账号中的手动选择入口。
- 新添加的账号及首次使用的新协议自动生成独立指纹，按“QQ 号＋具体协议”分别保存；切回已有协议时复用该协议原来的指纹。

## 升级说明

通过在线更新或对应系统完整安装包升级，保留原有 data 目录和插件数据。在线更新成功后框架自动重启。

旧账号保留现有登录身份和缓存，即使此前共用指纹，也不会在升级时自动拆分。只有手动确认“刷新指纹”才会更换当前协议的指纹并清理对应登录缓存，之后需要重新登录；其他账号和协议保持不变。

插件开发者请同步更新 SDK：独立指纹创建、删除接口已移除，添加和编辑账号不再接受指定指纹；需要主动更换时请使用新的刷新接口。详见[账号指纹管理迁移说明](https://github.com/Carlor-Official/Mengka-NT/blob/main/docs/managed-fingerprints.md)。
