# 萌卡 NT v2.8.1

## 新增

- 运行状态接口 `get_status` 补充登录时间，可同时读取账号的登录时间和上线时间。

## 优化

- 统一说明两个时间字段的含义与单位，并同步 SDK 和官网 API 文档。

## 修复

- 修复擂台任务结束后面板仍可能显示占用状态的问题，并优化执行中的提示。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新完成后框架会自动重启，账号按原有登录设置恢复。

升级后，`get_status` 返回 `stat.login_time`（登录时间）和 `stat.online_time`（上线时间），均为秒级 Unix 时间戳；没有记录时为 `0`。已有上线时间字段的位置和含义保持不变。
