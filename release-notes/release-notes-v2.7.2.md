# 萌卡 NT v2.7.2

## 优化

- 云核心校验成功后加密缓存到本机；重启或升级后核心未变化时复用缓存，减少重复下载。
- 多个账号共用云核心初始化过程，降低集中登录时的重复请求与网络开销。

## 修复

- 修复单个账号登录超时或取消时，连带中断框架共享云核心下载的问题。
- 配合算法端优化云核心传输，缓解集中更新后授权请求超时、框架信息长时间显示“待同步”的问题。

## 升级说明

通过在线更新或对应系统完整安装包升级，保留原有 data 目录和插件数据。在线更新成功后框架自动重启。

本地仅缓存已校验的云核心代码，每次启动仍需连接算法系统取得有效授权。首次使用、缓存损坏或云核心变化时会重新下载；不会从缓存恢复授权档位或 QQ 签名会话。

已使用加固云核心的账号不能直接回退到 v2.6.8 或更早版本，请勿使用旧版程序覆盖升级后的安装。
