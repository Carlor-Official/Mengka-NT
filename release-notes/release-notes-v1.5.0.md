# 萌卡 NT v1.5.0

## 新增

- 新增完整用户端：支持访客注册、可选邮箱验证码、用户封禁/解禁、余额管理和独立用户会话。
- 新增商品与支付业务：支持余额支付和在线支付，支付回调成功后自动确认订单并为所选 QQ 续期。
- 新增账号续费入口，可使用卡密或已上架商品为单个 QQ 延长有效期。
- 新增 SMTP 邮箱配置、测试邮件以及与框架 UI 配套的 HTML 邮件模板。
- 新增购买商品与账号掉线邮件通知；未配置自定义邮箱时默认发送到对应 QQ 邮箱。

## 调整与优化

- 用户端账号列表统一为管理端账号表格样式，并补齐搜索、状态、会话、环境及更多操作。
- 用户端账号登录改为直接使用框架账号状态，不再以页面缓存代替真实在线状态。
- 用户端支持找回并同步框架内已有 QQ，卡密续费改到账号操作中完成。
- 用户列表改为用户维度管理用户端开放状态、注册规则、余额和名下 QQ。
- 卡密列表将“使用用户”和“使用账号”拆分显示，便于区分归属与实际续费对象。
- 商品交易记录新增支付渠道，区分支付宝、微信、QQ 钱包、余额和管理员调整。
- 等级任务移动到账号更多操作中，减少独立菜单并保持账号维度操作。
- 登录协议、设备指纹和节点显示与框架配置统一。
- 官网 API 文档同步 v1.5.0，共覆盖 85 个公开 action。

## 修复

- 修复框架重启后缓存登录未先恢复最新账号状态，导致接口鉴权失败并触发重复安全验证的问题。
- 修复普通 Qzone 请求的 W21/S26 被误判为全局会话失效、清空缓存并强制账号下线的问题。
- 修复账号心跳、登录票据刷新与网页票据刷新之间状态覆盖，提升长时间在线和重启恢复稳定性。
- 修复在线时长异常、用户端无账号时菜单无法切换以及余额流水金额符号重复等问题。
- 修复在线支付已有成功记录但框架未到账的问题；支付窗口现在自动检测结果，无需用户点击“我已支付”。

## 升级说明

- 升级前请停止旧进程并完整备份现有 `data` 目录。
- 解压后替换程序和静态资源，保留原数据库、账号缓存与配置文件。
- 如果旧缓存已经被判定失效，首次升级后仍需手动完成一次账号验证；之后会按新流程保存并恢复缓存。
