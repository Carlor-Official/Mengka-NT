# 萌卡 NT v2.1.8

- 修复框架在线更新后托管插件可能残留旧进程、无法重新启动的问题，更新前会先完成插件停止。
- 修复 Linux 托管插件可能随调用线程退出而意外结束的问题，改善连续启动、停止和热重启的稳定性；启动失败时显示更明确的进程退出原因。
- 修复 Linux 插件私有临时目录不可写，导致部分打包插件无法启动的问题。
- 新增官方用户系统的同路径门户配套：普通用户可通过框架域名或 IP 下的 `/user/` 访问；保存门户设置后由框架重启插件并反馈恢复状态。需要配套用户系统 v2.0.11，并在官网审核上架后通过插件市场更新。
- 调整 `buy_pet_bath_item`：购买数量业务校验仅要求 `count > 0`，移除购买前的目录查询、数量上下限和步进限制；同步调试说明、SDK 和 API 文档。感谢协议资料贡献者 **星空花海**。

## 升级说明

1. 已安装官方用户系统的用户，请在 v2.0.11 官网审核上架后更新配套插件，再使用一键门户。已有独立域名或端口配置继续保留，普通用户入口与管理端权限隔离。
2. 托管插件生命周期修复从本版生效。从旧版本首次在线升级时，旧程序仍执行旧的停止逻辑；如升级后仍提示旧进程占用，请完整停止旧框架及其插件后再启动本版。
3. 手动升级前备份 `data`，停止框架与托管插件，替换主程序和 `public`，保留原有配置及业务数据。使用托管插件的 Linux 框架须沿用 root 系统服务及所需隔离依赖。
4. QQ 宠物接口名称、请求参数不变。购买响应失败或结果未知时，先核对库存，不要自动重复购买。
