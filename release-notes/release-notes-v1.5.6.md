# 萌卡 NT v1.5.6

## 更新

本次版本重点修复少数环境中同一条 QQ 消息被重复下发、导致插件重复回复的问题，并补齐 user 端用户资料、密码与邮箱安全管理流程。

### 用户密码安全

- user 端登录窗口新增“找回密码”，通过账号已绑定邮箱接收验证码并设置新密码。
- 框架未配置可用邮箱服务时会明确提示联系管理员，不会误报验证码已发送。
- 管理端用户编辑支持单独修改用户密码；修改后会撤销该用户现有 user 端会话。
- user 端右上角头像新增“用户信息”，用户可验证原密码后修改自己的登录密码。
- 用户自行修改密码时保留当前会话，并自动退出其他设备上的用户会话。

## 修复

### 消息重复下发修复

- 修复同一条群聊或好友消息因 QQ 推送重投、不同好友推送类型重复到达而被插件执行两次的问题。
- 按 QQ 账号、会话范围和协议消息标识进行短时去重，不再按消息文本判断，避免两条内容相同但实际不同的消息被误拦截。
- 多账号、不同好友、不同群聊以及分片消息相互隔离，不影响正常消息接收。
- 并发收到同一推送时仅下发一次，插件无需增加自己的去重代码。

## 新增

### 用户邮箱管理

- 用户信息中展示只读用户账号和当前邮箱验证状态。
- 支持首次绑定邮箱，必须通过新邮箱验证码后才会生效。
- 支持安全换绑邮箱：先验证原邮箱，再验证新邮箱，两个步骤全部完成后才会更新。
- 增加验证码有效期、发送频率、错误次数和邮箱唯一性校验，降低邮箱被冒用风险。
- 兼容旧版本已绑定邮箱；框架重启不会把尚未完成验证的新邮箱错误标记为已验证。

## 升级说明

- Windows 10/11 64 位：下载 `mengka-nt-v1.5.6-windows-amd64.zip`。
- Linux x86_64：下载 `mengka-nt-v1.5.6-linux-amd64.tar.gz`。
- Linux ARM64：下载 `mengka-nt-v1.5.6-linux-arm64.tar.gz`。
- 升级前请停止框架并备份原有 `data` 目录。完整解压新包后替换程序与前端资源，不要用空数据目录覆盖现有运行数据。
- 邮箱找回、绑定和换绑依赖“设置 → 应用”中的邮箱配置；未配置时其他框架功能不受影响。
- 本次未改变插件 WebSocket API，现有插件无需修改。
