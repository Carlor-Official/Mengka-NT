# 萌卡 NT v1.5.9

## 更新

本次版本修复单次签名服务网络波动导致在线 QQ 被立即断开的缺陷。v1.5.8 对 W21 的防护仍然有效：框架不会发送未签名心跳，也不会在收到明确的会话失效响应后继续重试旧会话。

## 修复

- 签名服务请求遇到传输错误时，自动使用全新连接重试一次，降低失效 Keep-Alive、连接重置和短时网络抖动造成的失败。
- MSF 心跳第一次失败后保留当前连接，并在 15 秒后重试；连续失败达到 3 次才按网络异常离线。
- 心跳恢复成功后自动清零连续失败次数，下一次心跳恢复正常间隔。
- W21/S26、框架版本过低等明确拒绝仍按原有原因立即停止，不会被误记为普通网络断开。
- 细分超时、连接重置、连接拒绝、连接关闭、DNS 与 TLS 错误提示，同时继续隐藏签名服务地址和敏感参数。
- 心跳签名失败时继续禁止发送未签名请求，不以容错为由降低安全校验。

## 验证

- Go 全量测试和 `go vet ./...` 通过。
- 前端 45 项业务与移动端回归测试通过，生产构建通过。
- 官网教程生产构建通过。
- Linux amd64 测试环境已验证 v1.5.9 启动、网页访问、1060221 缓存登录，并完成一轮签名、MSF 发送与成功回包的完整心跳。
- Windows amd64、Linux amd64、Linux arm64 三个平台外发包均完成内容与架构审计，未包含源码、数据库、日志、密钥或环境文件。

## 升级说明

- v1.5.8 可直接升级到 v1.5.9。
- 升级前请停止框架并备份现有 `data` 目录。
- 完整解压新包后替换程序与前端资源，不要使用新包中的空数据覆盖原有运行数据。
- Windows 10/11 64 位：下载 `mengka-nt-v1.5.9-windows-amd64.zip`。
- Linux x86_64：下载 `mengka-nt-v1.5.9-linux-amd64.tar.gz`。
- Linux ARM64：下载 `mengka-nt-v1.5.9-linux-arm64.tar.gz`。
- 本 Release 只包含萌卡 NT 框架外发包，不包含 Android APK、QSign 服务或其他独立项目附件。
