# 萌卡 NT v1.5.1

## 更新

本次版本集中整理了近期已经完成的初始化、运行环境、用户系统、账号登录和管理功能调整，首次部署与日常使用流程都有明显变化。

### 首次安装与运行环境

- 新增网页版首次安装向导：阅读使用协议、设置服务端口并使用萌卡 NT 官网个人令牌绑定管理员，首次启动不再依赖终端交互输入。
- Windows 外发包内置已编译的 Mengka Docker 环境安装器；Linux 会根据系统环境自动准备 Docker。
- 框架会自动检查并部署 PostgreSQL、Redis 与 FFmpeg。准备期间先保持本地模式可用，环境就绪后自动迁移数据并切换，不需要再单独下载工具或手工点击安装容器。
- 自动准备失败时会保留本地数据方案并继续重试，避免因为 Docker 或数据库暂时不可用而导致框架无法打开。
- 数据库方案切换会同步迁移现有业务数据；不具备 Docker 条件的设备仍可使用 SQLite 与进程内缓存。
- 优化在线更新后的重启流程，并修正 Linux 无交互环境首次启动可能出现的 EOF 问题。

### 用户系统与账号管理

- 用户系统支持用户自主注册、邮箱验证码和一个用户管理多个 QQ。
- 用户可通过卡密添加或续费 QQ，也可通过扫码找回已经存在于框架中的账号；账号到期后会自动停止登录，续费后可继续使用。
- 用户端新增账号列表、账号切换、登录、安全验证、扫码找回、续费和商品购买等完整操作。
- 管理端重新整理用户、卡密、商品和支付页面，支持用户封禁/解禁、余额增减、账号有效期和交易记录管理。
- 商品支持余额或在线支付，并可按商品和 QQ 独立设置购买成功邮件通知。

### 登录与运行稳定性

- 修复密码登录后主登录票据未完整刷新、账号未正确上线的问题。
- 修复后端重启时缓存登录重复换票、卡在检查缓存或错误清除有效缓存的问题。
- 仅在明确确认登录凭证失效时才让账号离线，普通接口失败、功能限制或临时网络错误不再误伤在线账号。
- 优化心跳、服务端推送回执、签名设备匹配和登录票据定时刷新，降低长时间运行后的异常离线概率。
- 优化 QQ 服务节点连接与重试处理，提升网络波动时的恢复能力。

### QQ 功能与任务

- 完善“参与盲盒签并成功发布空间”等级任务，可获取盲盒签图片并发布到 QQ 空间。
- 修正 QQ 空间相关请求的登录票据更新与未处理数量解析。
- 补充相关接口测试和业务契约测试，覆盖初始化、用户注册、账号登录、支付、邮件与缓存恢复流程。

### 下载说明

- Windows 10/11 64 位：下载 `mengka-nt-v1.5.1-windows-amd64.zip`。
- Linux x86_64：下载 `mengka-nt-v1.5.1-linux-amd64.tar.gz`。
- Linux ARM64：下载 `mengka-nt-v1.5.1-linux-arm64.tar.gz`。

升级前建议备份 `data` 目录。解压新版并替换程序与前端资源后启动即可，已有数据会按当前选择的数据库方案继续使用或自动迁移。

## 新增

### 管理员与邮件通知

- 管理员身份改为与萌卡 NT 官网账号绑定，头像、显示名称与账号信息会同步显示。
- 应用设置新增 SMTP 邮箱配置和测试邮件功能。
- 新增注册验证码、QQ 掉线和购买成功邮件模板；账号可独立决定是否接收掉线或购买通知。
