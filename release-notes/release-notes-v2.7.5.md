# 萌卡 NT v2.7.5

## 新增

- 算法最低版本要求触发强制自动更新后，若已开启缓存登录，新版本首次启动会尝试一次缓存自动登录，保留原“自动登录”开关设置。

## 修复

- 修复通过 HTTP IP＋端口访问时，插件访问设置中的“复制配置”无法使用的问题。
- 同步修复源码中协议调试工具的结构树、Go 代码及 Hex 复制兼容问题。

## 优化

- 优化算法服务连接异常处理，减少重复失败请求，完善更新框架、重启等处理提示。
- 完善复制操作的成功与失败反馈；浏览器限制复制时显示手动复制提示，避免保留过期的成功状态。

## 升级说明

通过在线更新或对应系统完整安装包升级，保留原有 data 目录和插件数据。在线更新成功后框架自动重启，更新后刷新管理页面。

强制更新后的一次性缓存登录仅在用户开启缓存登录时生效，不会永久修改自动登录设置。普通更新与后续手动重启仍遵循原设置。

本次升级保留现有账号、设备指纹及登录缓存；如需更换指纹，仍须在账号编辑中手动确认“刷新指纹”。
