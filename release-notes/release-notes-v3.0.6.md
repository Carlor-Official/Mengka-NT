# 萌卡NT v3.0.6

## 新增

- 新增版本停用后的强制在线更新页面。当前版本被停用后暂停框架业务，保留管理员登录和在线更新入口，更新并通过验证后恢复使用。
- 新增 IPC 插件 Docker 环境检查与准备功能，导入插件统一在隔离容器中运行，业务数据独立保存。
- 新增 Telegram 机器人在线领取注册卡，每个 TG 账号限领一张，重复领取返回原注册卡。
- 新增机器人私聊授权查询和迁移码申请，可查看本人 UID、当前权益，并申请 24 小时有效的迁移码；迁移保留 UID 和权益，完成后旧部署立即失效。
- 新增验证端 Telegram 领取来源展示，可在用户详情查看绑定的 TG 账号和注册卡领取时间。

## 优化

- 更新全站界面，统一页面布局、控件和主题配色，优化桌面与手机端的导航和交互。
- 调整 Free 权益：不再提供自定义发包、等级加速、扫码授权、红包领取及红包消息推送功能；账号页面正常扫码、免扫登录保留。
- 调整 Plus 权益：上述功能要求 QQ 至少 32 级，使用时核验最新等级；Pro 沿用原有规则。
- 统一框架为单机运行模式，移除服务节点管理和账号节点代理配置。
- 同步调整账号、插件、等级任务、API 调试、SDK 和接口文档，取消节点选择。
- 补齐 API 调试和官网文档的适用协议、参数说明与调用示例，同步接口权益要求和停用标记。
- 统一框架及验证端的时间展示、日志、每日统计和定时任务时区为北京时间（Asia/Shanghai）。
- 优化 Linux 扫码登录的进度显示与状态回查，区分等待手机确认、正在登录和登录完成。
- 优化设备指纹生成的网络兼容性，系统 DNS 解析异常时自动尝试备用解析，继续保持 HTTPS 证书校验。
- 优化插件运行环境下载的网络兼容性，减少重复下载和环境准备失败。
- 更新“关于应用”和初始化页面的官网入口，统一指向 https://mengka.net。
- 优化小游戏擂台任务的授权与创建流程，优先复用已有有效擂台，避免重复创建，并按 QQ 返回的任务状态确认加速结果。
- 加强机器人领卡和迁移申请的安全校验，保护注册卡与迁移码，避免重复发卡和冒领。

## 修复

- 修复验证服务临时断线或心跳超时导致框架直接退出的问题，暂停业务并保留管理员恢复页面，重新通过授权和安全校验后自动恢复。
- 修复在线更新依赖 GitHub 发布账号连接状态的问题，直接读取已配置并启用的更新信息与下载地址。
- 修复部分网络下 QQ 经典农场资源包下载超时的问题，增加同域备用地址连接，避免多个账号重复下载失败的共享资源包。
- 修复 Linux 扫码确认后，部分请求连接中断导致登录无法完成的问题。
- 修复等级任务中“电脑 QQ 在线”免扫登录授权失败的问题，统一与账号页面的免扫登录处理。
- 修复数据库初始化文件缺失时，框架反复重启、初始化页面持续等待的问题。
- 修复旧版升级后，部分环境因数据库时间字段不兼容导致启动失败的问题。
- 修复框架内 API 调试中，自定义发包参数校验未同步的问题。
- 修复 API 调试中嵌套参数、扫码授权必填参数与实际接口不一致的问题。
- 修复部分任务连接失败时，实际错误被误判为操作取消、提示不准确的问题。
- 修复反向代理缓冲较大插件包时，环境检测结果过期导致导入被拒的问题。
- 修复账号列表最后活跃时间缺失的问题。
- 修复账号最近日志记录不完整的问题，补齐连接、心跳、资料刷新及消息收发摘要。
- 修复账号列表排序在切换页面后恢复默认的问题，保留管理员选择的排序方式。

## 升级说明

升级前请备份完整 data 目录与插件数据。手动升级时，请先停止框架，再替换程序和配套 public 静态资源。保留原 data 目录，无需重新使用注册卡。

本次发布后，验证服务将停止旧版本准入。旧版无法在线更新时，请按上述步骤手动升级。

使用 IPC 插件前，请准备 Docker 的 Linux 容器环境，并使用与目标架构匹配的 Linux 插件包。

服务节点相关接口和节点参数已取消。使用插件或自行对接 API 时，请同步更新适配版本。

已通过机器人领取注册卡的用户，可在机器人私聊发送“我的授权”或“生成迁移码”。迁移仅保留 UID 和授权权益，QQ 账号及插件业务数据请另行备份。
