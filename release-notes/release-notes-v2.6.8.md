# 萌卡 NT v2.6.8

## 新增

- “关于应用”新增更新日志页签，展示最新正式版的版本号、发布日期、当前安装状态和更新内容。

## 优化

- 更新日志采用上方版本信息、下方完整正文的布局，适配手机竖屏、明暗模式与主题色。
- 日志支持刷新、读取失败后重试及查看历史版本；切换页签不会重复加载。
- 统一历史版本更新日志的标题、分类与排版，补齐日志目录和模板。

## 修复

- 修复没有导入插件时，插件列表自动刷新反复出现空白加载卡片、页面闪烁的问题。

## 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新成功后框架会自动重启。

从仍使用安卓 9.1.70 的旧版本升级时，请参考 v2.6.7 的升级说明，将账号切换为 9.2.70 后重新登录。
