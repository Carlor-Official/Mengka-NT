# 萌卡 NT v2.2.0

- 简化托管插件运行方式：插件作为独立子进程启动，使用框架当前运行用户，移除隔离环境、独立低权限用户和插件白名单依赖，改善旧环境升级后的启动兼容性。
- `send_packet` 开放为普通 API，已认证的正向、反向及托管插件可直接调用；保留服务 Token 认证、参数校验和账号权限检查。
- 插件管理入口跟随当前设备的框架长期登录，刷新访问令牌不再导致插件后台掉线，取消独立的 8 小时超时；退出框架或撤销该登录后同步失效。
- 更新在线调试、插件接入说明、官网 API 文档和正反向 Node.js SDK。

## 升级说明

- 请同步更新框架主程序、前端和 Node.js SDK 至 2.2.0。手动升级同时替换主程序与 `public`，保留 `data` 中的配置与业务数据。
- 插件继承框架运行用户的系统权限；框架由 root 运行时，插件同样由 root 运行。插件不再具有文件系统隔离边界，请按实际使用需要设置框架运行用户，并仅安装可信插件。
- 已迁移的插件程序目录和业务数据继续保留，不自动修改系统服务用户或目录归属。若更换框架运行用户，请确保其能访问实际程序与数据目录；原先手动停止的插件保持停止。
- 本版框架调用 `send_packet` 不再需要专属 Key、插件白名单或算法授权。普通服务 Token 和账号授权仍然有效，原始发包的响应由具体协议与 QQ 服务端决定。
