# 萌卡 NT v3.0.2

## 优化

- 完善在线更新的下载线路、安装包校验与失败回退流程。
- 完善授权信息展示，可分别查看 Plus、Pro 的有效期与当前生效权益。
- 优化分享账号预览，实时刷新时不再反复生成图片，仅在下载时生成 PNG。
- 完善听歌金币领奖流程，领奖后刷新新解锁奖励，最多处理三轮。
- 补充设备指纹创建、群历史消息、QQ 宠物鼓励及 IPC 账号委托接口。
- 更新官网 API 文档，统一补充适用协议、参数与调用说明。

## 修复

- 修复 Plus 权益仍按 Free 等级门槛限制 API 和等级任务的问题。Free、Plus、Pro 分别使用 48 级、16 级和不限制等级的规则。
- 修复权益调整、续费或到期后的状态同步问题。Pro 到期后，有剩余 Plus 权益则回到 Plus，否则回到 Free；加强有效期与权限变更校验。
- 修复部分设备标识返回格式导致随机指纹创建失败的问题。
- 修复 Windows 部署下 Linux 账号免扫登录的兼容性问题。
- 修复插件导入在上传较慢时失败的问题，完善 IPC 账号授权校验。
- 修复元宝任务的材料获取与完成确认问题。
- 修复部分等级任务缺少“+0.5 天”等奖励标注的问题。

## 升级说明

升级前请备份完整 data 目录与插件数据。手动升级时，请先停止框架，再替换程序和配套 public 静态资源。保留原 data 目录，无需重新使用注册卡。

首次部署请下载对应系统的完整安装包，使用注册卡完成初始化。Windows 与 Linux 均提供 AMD64 / x86_64 安装包。
