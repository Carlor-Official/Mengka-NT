# 萌卡 NT v1.4.3

## 新增

- 全新部署时，在 Docker 可用后自动安装并启动 PostgreSQL、Redis、FFmpeg，无需再进入容器页面逐个点击安装。
- 自动安装会使用框架已配置的镜像加速线路，并在网络恢复后继续完成未完成的项目。

## 修复

- 修复部分 Windows 用户已经启动 Docker，框架仍持续提示需要重启的问题。
- 修复 PostgreSQL 容器重启或短暂断开后，节点仍提示主数据库未连接的问题。
- 修复长时间运行时偶发数据库占用、页面请求中断或需要强制刷新的问题。
- 优化 Docker、PostgreSQL 与 Redis 的运行状态恢复，框架重启后会自动重新连接。

## 升级说明

- 覆盖程序文件即可升级，请保留原有 `data` 目录。
- 首次运行本版本时，如果三个内置容器尚未安装，框架会在后台自动下载安装；实际用时取决于当前网络和镜像线路。
- 自动准备完成后会记住状态，之后用户主动停止或卸载容器时不会被后台强制恢复。
