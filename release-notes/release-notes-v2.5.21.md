# 萌卡 NT v2.5.21

## 更新

- 更新管理控制台界面，完善导航、概览与移动端体验。
- 完善账号、等级任务、设备指纹和插件管理的功能衔接。

- 修复部分入口、状态展示及跨页面操作衔接问题。
- 统一插件导入与接入规范，清理旧协议和旧包兼容。

升级说明：请更新完整外发包并刷新管理页面，前端和后端应使用同一版本。升级前备份运行数据，保留原有账号与配置。

插件升级：仅支持 Schema 3 清单、显式 WebSocket v1 或原生 IPC v1（API 1）。旧包及缺少完整安装校验记录的插件需按当前 SDK 重新打包导入；业务数据可保留。
