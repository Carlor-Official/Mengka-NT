# 萌卡 NT v1.9.4

本版本基于 v1.9.3 的 Linux QQ 稳定版本，重点升级专属 Key 的领取、查看与固定绑定体验。

## 核心更新

- 框架端可直接读取当前官网账号可用的专属 Key，不再需要手动复制和粘贴完整 Key。
- Key 下拉清单展示名称、到期时间、允许调用的 API 范围和每分钟限额，便于选择正确授权。
- 选中 Key 后固定绑定到当前框架实例；浏览器只提交 Key ID，完整凭证仅经官网、算法系统与框架服务端安全链路传递。
- 增加清单加载、空状态、异常重试和移动端适配，提升配置过程的可理解性与可用性。
- 保留 v1.9.3 的 Linux 扫码登录与 Android 独立登录链路，不改动协议和签名流程。

## 升级说明

升级前请完整备份原目录中的 `data`。停止旧版本后替换程序文件和 `public` 前端资源，并保留原有数据库与管理员配置。

外发包不包含数据库、管理员配置、日志、源码、密钥或 Git 元数据。专属 Key 清单功能需官网、算法系统与框架端使用同一套身份验证配置。
