# 萌卡 NT v1.5.12

本版本开始按 NapCat/OneBot 分类补齐框架公开 API，首批完成系统基础接口和消息发送兼容接口。接口不是只增加同名入口，已同步参数适配、返回契约、插件权限目录、Node.js SDK 和开发文档。

## 新增系统基础接口

- `get_login_info`：获取当前在线 Bot 的 QQ 号和昵称。
- `get_status`：同时检查框架登录状态与 MSF 连接状态，并返回收发计数和在线时长。
- `get_version_info`：返回萌卡 NT 当前版本和 OneBot 兼容协议版本。
- `can_send_image`、`can_send_record`：返回当前在线账号的图片、语音发送能力。

## 消息兼容接口

- 新增 `send_private_msg`，复用成熟的好友发送链路，兼容 NapCat/OneBot 名称与 `{message_id}` 返回值。
- 新增 `send_msg`，支持 `private`、`group` 两类目标；省略 `message_type` 时会根据唯一的 `user_id` 或 `group_id` 安全判定。
- 两个兼容接口的 `message` 均支持纯字符串、单个消息段和消息段数组，不需要插件手工包装纯文本。
- 参数为空、目标冲突、消息类型非法或发送回执缺失时均明确失败，不会错误报告发送成功。

## 插件与开发者同步

- 框架公开能力目录从 85 个增加到 92 个 action，插件市场可直接勾选本次新增的 7 个接口。
- 正向和反向 Node.js SDK、示例插件 SDK 同步到 92 个 action。
- 开发文档新增 7 个接口页，并附带 NapCat 175 个 action 的差异清单和后续分批实现顺序。
- 插件授权仍以萌卡 NT 官网审核通过的 API 与事件快照为唯一标准，不依赖安装包内清单文件。

## 验证情况

- Go 全量测试与 `go vet` 通过。
- 新增系统接口和消息兼容接口的注册、参数、消息归一化与返回契约测试通过。
- 前端 45 项业务与移动布局测试、生产构建通过。
- 官网插件能力目录 92 项无重复，Halo 插件 25 项测试通过。
- 开发文档生产构建与四份 Node.js SDK 语法检查通过。
- Windows AMD64、Linux AMD64、Linux ARM64 三平台包完成架构、执行权限、文件白名单、敏感文件和构建路径审计。

## 升级说明

1. 停止旧版框架并备份框架目录，尤其是现有 `data` 目录。
2. 解压对应平台安装包，替换程序与 `public` 前端资源。
3. 保留原有业务数据、配置、插件和运行目录，不要使用新包中的初始化数据覆盖现有数据。
4. 插件如需调用新增 API，请在萌卡 NT 官网的插件权限中勾选对应 action，并重新完成审核/安装授权。
