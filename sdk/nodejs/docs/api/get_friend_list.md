# get_friend_list

获取 Bot 的完整好友列表。萌卡NT会自动完成分页。

分页读取全部好友。分页请求失败时返回错误，不返回部分列表。

内部单页请求调整为200条，避开较大分页响应发生记录缺口的边界；这不是最终好友数量上限，插件无需自行传递分页游标。

整批读取上限为60秒，调用方设置的更短超时仍然有效。资源保护上限为128页、100000条好友记录或64 MiB响应；触及上限时明确失败，不截断成功返回。`total_count` 是最终返回的好友条数，不是单页协议的结束标记。

## 调用方式

```js
const result = await api.get_friend_list(self_id)
```

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `self_id` | number | 是 | 在线 Bot QQ 号 |

## 返回值

```js
{
  friends: [],
  total_count: 0,
  self_uin: 123456789,
}
```
