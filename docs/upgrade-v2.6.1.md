# v2.6.1 账号管理与交互修复

升级前备份 data 目录和插件数据，使用对应系统与架构的完整外发包更新，保留已有数据并刷新管理页面，无需重新初始化管理员。

- 已有账号的协议选择与配置保持不变，继续支持 Android 9.1.70、9.2.70 和 Linux。
- 离线账号切换平台时迁移关联记录；切换后使用目标协议重新登录。同号目标账号已存在时，可直接打开该账号编辑，两边数据分别保留。
- QQ 音乐任务仅在登录初始化的网络超时阶段有限重试。听歌上报、金币领取、兑换等操作不自动重放；提交后结果不明时仍应先刷新任务核对。
- 主题色采用原位渐变，配色仍由站点统一保存；明暗模式保留原有切换效果。
