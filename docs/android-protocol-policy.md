# Android 协议调整

当前 Android 登录仅支持 9.2.70（手机／平板），Linux 3.2.32 保持独立。

9.1.70 已停止提供协议配置、设备签名、Energy、附件与设备信息服务。旧协议配置文件不能重新启用该版本。

已有 9.1.70 账号和设备资料保留。升级后在账号列表中编辑该账号，选择 9.2.70，再重新登录；不会静默替换协议或把旧票据视为新协议的有效会话。协议编号 0/1 仍为 9.2.70 手机／平板，2/3 留空，Linux 仍为 4。

Android API 统一使用 9.2.70 云核心。签名失败不会降级为未签名请求；未知命令仍会被拒绝。API 请求参数和返回结构不变。

宠物好友及陌生人目录仍可能返回腾讯的低版本限制。已知真实 pet_id 时可直接调用相应查询接口；不能将目录受限返回为空列表或认定为业务成功。其他操作仍受账号权限、业务条件与腾讯验证要求约束。
