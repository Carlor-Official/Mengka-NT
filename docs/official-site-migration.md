# v2.4.0 本地管理员迁移

萌卡 NT v2.4.0 不再使用官网账号、个人令牌或 Halo 用户体系作为框架管理员身份。官网入口为 https://mknt.net，但框架管理登录不依赖官网在线状态。

## 从旧版本升级

1. 停止框架并完整备份 `data` 目录。
2. 完整替换框架程序和前端资源，保留原有数据目录。
3. 启动新版本并打开框架首页。
4. 系统检测到旧官网管理员记录后，会强制进入一次初始化页面。
5. 直接设置新的本地管理员账号和高强度密码，无需验证旧官网身份。

初始化会撤销旧管理会话，清空旧官网身份字段并写入本地 bcrypt 密码哈希。QQ 账号、指纹、节点、插件连接、插件实例、配置与业务数据不会因此删除。

已经使用本地 bcrypt 管理员的实例不会重复初始化。初始化完成后，管理员凭据只属于当前框架实例；忘记密码时不能再通过官网账号找回。

## 安全要求

- 不要在多个公网实例复用管理员密码。
- 暴露到公网时使用 HTTPS，并尽量限制后台访问来源。
- 备份中可能包含账号、插件和会话数据，应按敏感数据保存。
- 旧 PAT、官网密码和 Halo Token 不再是框架登录凭据，也不要填写到插件配置中。
