# v2.7.2 升级说明

更新对应系统完整安装包，前后端同时升级，保留 data 目录和插件数据。在线更新成功后框架自动重启。

已校验的云核心代码会加密保存到 data。升级或重启后核心未变化时，连接算法系统取得新的有效授权后复用缓存，避免重复下载大模块。缓存不包含授权档位、租约或 QQ 签名会话；缓存损坏或核心更新时会重新下载。

多个账号共用框架级核心初始化，单个账号登录超时或取消不会打断共享下载。配套算法端已支持缓存协商，旧客户端继续使用原有协议。封禁、授权变更与租约到期仍由云端验证。

首次启动或核心变化时仍需要下载，请保持网络畅通。保留原账号、设备指纹、插件和缓存登录设置，无需清空 data。已使用加固云核心的账号不能直接回退到 v2.6.8 或更早版本。
