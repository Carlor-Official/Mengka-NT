# v2.7.0 升级说明

更新对应系统完整安装包，前后端同时升级，保留 data 目录和插件数据。在线更新成功后自动重启。

本版本修复 Linux 崩溃监控辅助进程未回收的问题。原地升级时，新进程会接管同一主 PID 下遗留的子进程；后续重启会先回收当前监控子进程。不影响正常插件的退出状态和崩溃日志。

算法端需要支持授权变更通知。在线框架收到通知后重新校验授权并同步签名云配置；断网恢复后会重新同步，并保留原定时续期流程。普通网络故障不会被直接当作封禁，已生效的封禁会在重新鉴权时被拒绝。

已启用加固云核心的账号不能直接回退到 v2.6.8 或更早版本。保留原账号、设备指纹、插件和缓存登录设置。
