# v2.8.1 升级说明

保留原有 data 目录和插件数据，通过在线更新或对应系统完整安装包升级。在线更新完成后框架会自动重启，账号按原有登录设置恢复。

`get_status` 在 `stat` 中新增 `login_time`，并保留原有 `online_time`。两者分别对应账号页面的登录时间与上线时间，单位均为秒级 Unix 时间戳；没有记录时为 `0`，并非在线时长。Android 与 Linux 使用相同返回字段。

原有插件无需修改即可继续读取 `online_time`；需要显示登录时间时，再读取新增的 `login_time`。使用 JavaScript 格式化日期时，将秒级时间戳乘以 `1000`。
