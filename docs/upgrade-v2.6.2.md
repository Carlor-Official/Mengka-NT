# v2.6.2 云核心更新与框架重启

在线更新成功后会自动重启框架并加载最新云核心，无需重启服务器。手动更新时替换完整程序包，保留原有 data 目录与插件数据，再启动框架。

管理页面会提示云核心更新，可点击“立即重启框架”生效。重启会短暂断开账号与插件，恢复遵循原有缓存登录、自动登录设置。

本版本支持算法系统统一下发强制重启指令。已登记且授权正常的在线框架约一分钟内接收后自动重启，无需本地管理员再次确认；指令有效期为 24 小时，同一安装实例对每条指令最多执行一次。离线实例在有效期内恢复连接后执行，过期指令忽略。旧版本不支持此指令。

云签名核心已解除固定 64 会话限制，实际承载能力仍取决于机器资源。
