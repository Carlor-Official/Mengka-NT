# v2.7.4 升级说明

通过在线更新或对应系统完整安装包升级，前后端同时更新，保留原有 data 目录和插件数据。在线更新成功后框架自动重启，无需删除账号或重新初始化管理员。

设备指纹由框架自动管理。新账号及首次使用的新协议会自动生成独立指纹；旧账号保留原来的登录身份和缓存，即使此前共用指纹，也不会在升级时自动拆分。

需要更换指纹时，先将账号离线，在“编辑账号”中点击“刷新指纹”并确认。此操作只更新该账号当前协议的指纹并清理对应登录缓存，完成后重新登录；其他账号和协议保持不变。原“清空缓存”功能继续保留。

插件开发者需要同步更新 SDK。独立创建、删除指纹接口已移除，添加或编辑账号不再接受指定指纹 ID。请按账号指纹管理迁移说明接入新的刷新接口：https://github.com/Carlor-Official/Mengka-NT/blob/main/docs/managed-fingerprints.md

首次启动与重启时请保持网络畅通，等待框架初始化完成。
