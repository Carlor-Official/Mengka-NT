# v2.7.5 升级说明

通过在线更新或对应系统完整安装包升级，前后端同时更新，保留原有 data 目录和插件数据。在线更新成功后框架自动重启，随后刷新管理页面。

本版本修复普通 HTTP IP＋端口访问下的复制兼容问题，并完善复制成功与失败反馈。

算法服务明确拒绝请求后，框架会暂停自动请求并显示处理方式。请按页面提示更新到要求的版本，或在“框架设置 → 框架更新”中重启框架刷新云核心；网络波动允许后续自动重试。

仅由算法最低版本要求触发且成功完成的强制自动更新，会在新版本首次启动时尝试一次缓存自动登录，前提是用户已开启缓存登录。这个临时放行不修改“自动登录”开关，不会对没有有效缓存的账号执行密码登录。普通更新和后续手动重启仍遵循原设置。

现有账号、设备指纹与登录缓存保持不变，无需重新初始化管理员。新账号仍按 QQ 号和具体协议自动管理独立指纹，旧账号只有在手动确认“刷新指纹”时才更换对应身份。

首次启动与重启时请保持网络畅通，等待框架初始化完成。
